A list of like items, such as values or the steps of a story, as rows of text beside an image that alternate sides. For one section of text beside an image, use [Split](/blocks/split).

## Import

```tsx
import { Splits } from '@oztix/roadie-blocks/splits'
```

## Examples

### Marked

Rows of a marked title, subtitle, and description beside a square image,
alternating sides, starting with the image on the left. Each row's title is
an `h3` under the block's heading, and the images wrap below the text on
phones.


### Intent and emphasis

`intent` marks every title, and colours the highlights and actions. Without
one, the titles are marked in turn in info, brand, and brand-secondary, and a
row's own `intent` marks its title. `emphasis` sets the surface behind the
block, as a full-width band, or a panel with `contained`. `itemEmphasis` sets
every row's surface.

```tsx-live-expand id=intent-and-emphasis
<Splits
  preset='marked'
  intent='success'
  emphasis='normal'
  title='How payouts work'
  items={[
    {
      title: 'Doors close',
      description: 'Settlement starts automatically once your event ends.',
      image: { src: '/brand/photography/04.webp', alt: 'A staff member in a blue vest scanning a ticket on a phone at an event entry', width: 1280, height: 1007 }
    },
    {
      title: 'Money arrives',
      description: 'Your payout lands within days, without chasing it.',

    }
  ]}
/>
```

## Guidelines

<Guidelines>

<Guideline title='Keep the rows alike'>
  <Guideline.Do>
    Use Splits for three to six statements of the same kind, such as values or the steps of a story, each a sentence or two.
  </Guideline.Do>
  <Guideline.Dont>
    Don't use it for sections that each need their own pitch and actions. Stack [Split](/blocks/split)s instead, switching between `image-start` and `image-end`.
  </Guideline.Dont>
</Guideline>

<Guideline title='Give every row a photo'>
  <Guideline.Do>
    Pick photos that show each statement, so the rows read as a set.
  </Guideline.Do>
  <Guideline.Dont>
    Don't leave some rows without an image. The empty square draws the eye away from the text.
  </Guideline.Dont>
</Guideline>

</Guidelines>

## Tracking

Splits reports a view once it's half on screen, and a click on each action or
linked row, with its preset and position. A row's click reports its title.
