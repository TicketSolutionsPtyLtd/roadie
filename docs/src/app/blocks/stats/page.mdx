Key numbers as they were written, each with a spot illustration and a label.

## Import

```tsx
import { Stats } from '@oztix/roadie-marketing-blocks/stats'
```

## Examples

### Company facts

A heading over the numbers, which wrap as many to a row as fit. Each value is
a string, so it reads exactly as the editor wrote it.

```tsx-live-expand id=company-facts
<Stats
  preset='company-facts'
  title='By the numbers'
  description='The impact of genuine partnerships'
  items={[
    { value: '33,000,000+', label: 'tickets sold', illustration: 'Ticket' },
    { value: '22,000+', label: 'event organisers', illustration: 'MapPin' },
    { value: '20+', label: 'years in ticketing', illustration: 'Heart' },
    { value: '50+', label: 'full-time team', illustration: 'HighFive' },
    { value: '7 million+', label: 'fans each year', illustration: 'FlowerSpiral' }
  ]}
/>
```

## Guidelines

<Guidelines>

<Guideline title='Answer first'>
  <Guideline.Do>
    Say what the numbers prove in the title or description, such as `The impact of genuine partnerships`, before the numbers do.
  </Guideline.Do>
  <Guideline.Dont>
    Don't title the block with a bare label, such as `Stats`.
  </Guideline.Dont>
</Guideline>

<Guideline title='Keep to a few numbers that change rarely'>
  <Guideline.Do>
    Show three to six numbers, such as tickets sold or years in business, rounded and written as they should read, such as `7 million+`.
  </Guideline.Do>
  <Guideline.Dont>
    Don't show live or precise figures. The block shows each value exactly as written.
  </Guideline.Dont>
</Guideline>

<Guideline title='Set stats beside text with Split'>
  <Guideline.Do>
    Use [Split](/blocks/split)'s `text-and-stats` preset to set stats beside long-form text.
  </Guideline.Do>
  <Guideline.Dont>
    Don't stack a Stats block under a text block to fake the aside.
  </Guideline.Dont>
</Guideline>

</Guidelines>
