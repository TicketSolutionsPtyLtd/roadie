Opens a page with its title, as the page's main heading.

## Import

```tsx
import { Hero } from '@oztix/roadie-marketing-blocks/hero'
```

## Examples

### Page hero

The title sits over a photo, beside a muted, looping video. From a tablet
width, event photos fill the panel beside the video, and from a desktop
width, people photos sit beside the title. Each set of photos crossfades
while it's on screen.

```tsx-live-expand id=page-hero
<Hero
  preset='page-hero'
  title='Australia’s ticketing partner'
  titleHighlight='Australia’s'
  description='Australian owned and hosted, nationwide 7 days a week. Built on partnerships, powered by people and service.'
  actions={[
    { label: 'Talk to us', href: '/contact/sales' },
    { label: 'Create my event', href: 'https://studio.oztix.com.au' }
  ]}
  backgroundImage={{ src: '/brand/photography/08.webp', alt: '', width: 1280, height: 850 }}
  video={{
    src: '/blocks/hero-reel.mp4',
    poster: { src: '/brand/photography/01.webp', alt: 'Highlights from Velvet Dingo Fest', width: 1280, height: 854 }
  }}
  peopleImages={[
    { src: '/brand/photography/03.webp', alt: 'Two Oztix team members working at their desks', width: 1280, height: 1007 },
    { src: '/brand/photography/04.webp', alt: 'Event staff scanning tickets at the gate', width: 1280, height: 1007 },
    { src: '/brand/photography/11.webp', alt: 'Three Oztix team members on a couch', width: 1280, height: 911 }
  ]}
  eventImages={[
    { src: '/brand/photography/12.webp', alt: 'A crowd in a laneway strung with bunting', width: 1280, height: 854 },
    { src: '/brand/photography/07.webp', alt: 'Guests on the terrace at Lighthouse Fig Lawn', width: 1280, height: 854 },
    { src: '/brand/photography/06.webp', alt: 'A panel talking on stage at Ochre Kite Weekender', width: 1280, height: 854 }
  ]}
/>
```

### Page header

An eyebrow and a large title, for a page whose first block carries the
media.

```tsx-live id=page-header
<Hero
  preset='page-header'
  eyebrow='Our mission'
  title='We empower venues and event organisers to create thriving events and communities through genuine partnerships.'
/>
```

## Guidelines

<Guidelines>

<Guideline title='Answer first'>
  <Guideline.Do>
    Say what the page offers in the title, such as “Australia’s ticketing
    partner”, and back it up in one sentence.
  </Guideline.Do>
  <Guideline.Dont>
    Open with a slogan that makes the reader scroll to learn what the page is.
  </Guideline.Dont>
</Guideline>

<Guideline title='One hero, first on the page'>
  <Guideline.Do>
    Start the page with the hero. Its title is the page’s `h1`.
  </Guideline.Do>
  <Guideline.Dont>
    Put a second hero lower down. Use a block with an `h2` instead.
  </Guideline.Dont>
</Guideline>

<Guideline title='Pick the preset by its media'>
  <Guideline.Do>
    Use Page hero on a landing page with a background photo, a video, and at
    least two photos each of people and events.
  </Guideline.Do>
  <Guideline.Dont>
    Use Page hero without its photos, which leaves panels empty. Use Page
    header for a page that opens on its text, such as About.
  </Guideline.Dont>
</Guideline>

<Guideline title='Describe the photos that carry meaning'>
  <Guideline.Do>
    Give people and event photos, and the video’s poster, `alt` text that says
    what they show.
  </Guideline.Do>
  <Guideline.Dont>
    Describe the background photo. It’s decoration, so the hero drops its
    `alt`.
  </Guideline.Dont>
</Guideline>

<Guideline title='Mark one or two words'>
  <Guideline.Do>
    Mark the word the title turns on with `titleHighlight`.
  </Guideline.Do>
  <Guideline.Dont>Mark a whole phrase.</Guideline.Dont>
</Guideline>

</Guidelines>
