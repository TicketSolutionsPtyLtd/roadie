A file field that checks each file before taking it.

## Import

```tsx
import { FileUpload } from '@oztix/roadie-components/file-upload'
```

## Examples

### Default

With no children, `FileUpload` is a dropzone with the chosen file listed under it. Drop a file on it, paste one, or click it to choose one. The file's row shows its name, size and a preview (a thumbnail for an image, an icon for anything else), and its Remove button takes it out. The field holds the file as a `File[]` and keeps a hidden file input in step, so a form posts it under `name`. A second file replaces the first.

```tsx-live width=140
<Field>
  <Field.Label>Guest list</Field.Label>
  <FileUpload name='guests' accept='.csv' />
  <Field.HelperText>A CSV up to 1 MB. You can also paste one.</Field.HelperText>
</Field>
```

### Rules

`accept` takes the native syntax, such as `.csv`, `image/*` or `application/pdf`. `maxFileSize` and `minFileSize` are in bytes. A file that breaks a rule never joins the value: its message shows in `Field.ErrorText`, and `onReject` gets it with a code (`wrong-type`, `too-large` or `too-small`). Pick a file that isn't a CSV, or one over 1 MB, to see it.

```tsx-live width=140
<Field required>
  <Field.Label showIndicator>Guest list</Field.Label>
  <FileUpload name='guests' accept='.csv' maxFileSize={1_000_000} />
  <Field.HelperText>A CSV up to 1 MB.</Field.HelperText>
  <Field.ErrorText />
</Field>
```

### Single-image slot

For one image, stack `FileUpload.Dropzone` and `FileUpload.List` in the same grid cell of a box with the image's aspect ratio. Once there's an image, its preview covers the dropzone, which still takes a click or a drop to replace it. Its focus ring shows around the preview. A replaced image fades out over its replacement, since the rows share the cell. The row is `FileUpload.Item` with `FileUpload.ItemPreview` and `FileUpload.ItemRemove`, restyled by `className`. Give the preview `alt` text, since no name sits beside it.

```tsx-live width=140
<Field>
  <Field.Label>Event image</Field.Label>
  <FileUpload
    name='eventImage'
    accept='image/jpeg,image/png,image/webp'
    className='aspect-2/1 w-full *:col-start-1 *:row-start-1'
  >
    <FileUpload.Dropzone
      title='Drop an image, or choose one'
      className='h-full content-center'
    />
    <FileUpload.List className='pointer-events-none h-full *:col-start-1 *:row-start-1'>
      {(item) => (
        <FileUpload.Item className='relative border-0 p-0'>
          <FileUpload.ItemPreview
            alt={`Event image: ${item.file.name}`}
            className='size-full rounded-xl'
          />
          <FileUpload.ItemRemove className='pointer-events-auto absolute top-2 right-2 emphasis-floating is-translucent' />
        </FileUpload.Item>
      )}
    </FileUpload.List>
  </FileUpload>
  <Field.HelperText>A JPG, PNG or WebP, 2:1.</Field.HelperText>
</Field>
```

### States

`Field` sets `invalid`, `required` and `disabled` for the whole field.

```tsx-live layout=stack width=140
{/* Invalid */}
<Field invalid>
  <Field.Label>Guest list</Field.Label>
  <FileUpload accept='.csv' />
  <Field.ErrorText>Choose the guest list to import</Field.ErrorText>
</Field>
{/* Disabled */}
<Field disabled>
  <Field.Label>Guest list</Field.Label>
  <FileUpload accept='.csv' />
</Field>
```

### Composition

#### Bar

For one plain file in a dense form, compose the bar instead, as the [guidelines](#guidelines) say. `FileUpload.Control` is the bar, `FileUpload.Value` the name and size (a label, so a click opens the picker), `FileUpload.Clear` the remove button, which shows only while there's a file, and `FileUpload.Trigger` the button that reads "Choose file", or "Replace" once there's one. The bar takes drops too: while a file is over it, its border turns accent and it reads "Drop to add".

```tsx-live width=140
<Field>
  <Field.Label>Price list</Field.Label>
  <FileUpload accept='.csv'>
    <FileUpload.Control>
      <FileUpload.Value placeholder='No price list yet' />
      <FileUpload.Clear />
      <FileUpload.Trigger />
    </FileUpload.Control>
  </FileUpload>
</Field>
```

#### Rows

`FileUpload.List` takes a child function, as Autocomplete's list does, called with each `{ file, id }`. Compose the row from `FileUpload.Item`, `.ItemPreview`, `.ItemName`, `.ItemSize` and `.ItemRemove`. Return a `FileUpload.Item` to get the motion; any other markup goes as soon as its file does. Rows pop in, staggered after the files added with them, and a removed row fades and collapses before it goes.

```tsx-live width=140
<Field>
  <Field.Label>Tech rider</Field.Label>
  <FileUpload accept='.pdf,image/*'>
    <FileUpload.Dropzone title='Drop the rider, or choose it' />
    <FileUpload.List>
      {() => (
        <FileUpload.Item>
          <FileUpload.ItemPreview className='size-10' />
          <FileUpload.ItemName className='flex-1' />
          <FileUpload.ItemSize />
          <FileUpload.ItemRemove />
        </FileUpload.Item>
      )}
    </FileUpload.List>
  </FileUpload>
</Field>
```

#### Button only

A `FileUpload.Trigger` on its own is a plain button, for a toolbar or a row of actions.

```tsx-live
<FileUpload accept='.csv'>
  <FileUpload.Trigger>Import guests</FileUpload.Trigger>
</FileUpload>
```

## Guidelines

<Guidelines>

<Guideline title='Dropzone or bar'>
  <Guideline.Do code={`<FileUpload name='guests' accept='.csv' />`}>
    Use the dropzone, the default, whenever the file is an image or anything people need to see once it's added, more than one file can be added, or uploading is the main job of the page, section or dialog.
  </Guideline.Do>
  <Guideline.Dont code={`<FileUpload accept='image/*'>
  <FileUpload.Control>…</FileUpload.Control>
</FileUpload>`}>
    Never use the bar for images, for multiple files, or as the main action on a page.
  </Guideline.Dont>
</Guideline>

<Guideline title='Keep the bar for one plain file in a dense form'>
  <Guideline.Do code={`<FileUpload name='prices' accept='.csv'>
  <FileUpload.Control>…</FileUpload.Control>
</FileUpload>`}>
    Use the bar only when all of these are true: it's a single file that isn't an image, such as a CSV, PDF or document; it's one field among several in a dense form, where a dropzone would outweigh its neighbours; and it lines up with other inputs in a row or grid. A "Price list (CSV)" field in a long settings form is one.
  </Guideline.Do>
  <Guideline.Dont>
    Don't pick the bar to save space when the file is the page's job, such as on a CSV import page. That's the dropzone's place.
  </Guideline.Dont>
</Guideline>

<Guideline title='Say what the field takes'>
  <Guideline.Do code={`<Field.HelperText>A CSV up to 1 MB.</Field.HelperText>`}>
    Name the file type and size limit in the helper text, so people pick the right file first time. Accept a CSV by its `.csv` extension, since Windows often reports one as `application/vnd.ms-excel`.
  </Guideline.Do>
  <Guideline.Dont code={`<FileUpload accept='.csv' maxFileSize={1_000_000} />`}>
    Don't leave the rules for the error message to explain.
  </Guideline.Dont>
</Guideline>

</Guidelines>

## Accessibility

- Dragging is never the only way in. `FileUpload.Dropzone` is a button: Tab reaches it, and Enter, Space or a click opens the picker. `Field.Label` and its title name it, such as "Guest list Drop a file, or choose one". Pasting a file works anywhere inside the field.
- Each row's Remove is named for its file, such as "Remove guests.csv". After it, focus moves to the next row's Remove, the previous row's when it was the last, or the dropzone or Trigger when no files are left. A row that's collapsing is inert, so it takes no focus.
- `FileUpload.ItemPreview` has empty alt text by default, since the name sits beside it. Give it `alt` when it stands alone, as in the single-image slot.
- `FileUpload.Trigger` is a real button, so it works with a keyboard, switch access and voice control. `Field.Label`, the chosen file and the button's own text name it together, such as "Guest list guests.csv 2 kB Replace".
- The bar's click target is `FileUpload.Value`, a label for the hidden input, so the bar adds no focus stop. Its only stops are Clear and Trigger. Clear is named for the file, such as "Remove guests.csv", and focus moves to the Trigger after it.
- A rejected file's message shows in `Field.ErrorText`, which is announced, and the dropzone or button gets `aria-invalid` and points at the message.
- The hidden file input takes `required`, so a form won't submit without a file, and focus goes to the dropzone or button when it doesn't.
- `capture` opens the phone's camera instead of its file picker: `user` for the front camera, `environment` for the back.
