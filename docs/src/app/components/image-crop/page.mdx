Crops an image to a ratio, or free-form, by panning, zooming and turning it under a frame.

## Import

```tsx
import { ImageCrop } from "@oztix/roadie-components/image-crop";
```

## Examples

### Default

The frame stays still and the image moves under it. Drag to pan, and pinch or double-tap to zoom, on a touch screen or a trackpad. The controls under the crop area zoom, turn the image 90° left, straighten it, and reset the crop once it has changed. Focus the crop area to scroll, press `+`, `-` or `R`, or use the arrow keys.

Past an edge or a zoom limit the image gives way, then springs back when you let go, so there are never empty corners. The size chip shows the crop in the image's own pixels. `src` takes a URL, or a `File` or `Blob` such as one from `FileUpload`. To crop a picked image and put the result back into a form, follow the [image field recipe](/components/file-upload#image-field), which saves the crop with `cropImage`.

```tsx-live width=180
<ImageCrop
  src='/brand/photography/08.webp'
  aspectRatio={2}
  label='Event image'
/>
```

### Minimum size

`minWidth` and `minHeight` are the smallest crop in the image's own pixels. Zoom stops before the crop drops below them, so an event image is never under 1200 × 600px. At the limit the size chip turns to a warning that says so, and nudges if you try to go further. An image smaller than the minimum says what it needs. An E-ticket banner is 10:3, at least 1000 × 300px.

```tsx-live width=180
<ImageCrop
  src='/brand/photography/03.webp'
  aspectRatio={10 / 3}
  minWidth={1000}
  minHeight={300}
  label='E-ticket banner'
/>
```

### Free-form

Leave out `aspectRatio` and the frame starts as the whole image, with handles on its corners and edges. Drag one and the opposite corner or edge stays where it is, or hold Alt to resize about the centre. Drag past the crop area and the image zooms out to take in more, up to the whole image. When you let go, the frame moves back to the centre and grows to fill the crop area, and the image zooms with it. A quarter turn turns the frame too, and Reset goes back to the whole image. `minWidth` and `minHeight` each set the smallest their own side can be. A homepage image can be any shape.

```tsx-live width=180
<ImageCrop
  src='/brand/photography/02.webp'
  minWidth={800}
  minHeight={400}
  label='Homepage image'
/>
```

### Avatar

`shape='circle'` changes only the mask. The value is still a rectangle, so crop the image to it and round it where it shows, as `Avatar` does.

```tsx-live width=140
<ImageCrop
  src='/brand/photography/05.webp'
  aspectRatio={1}
  shape='circle'
  minWidth={200}
  label='Profile photo'
/>
```

### Straighten

`ImageCrop.Straighten` is a dial that tilts the image up to 45° either way, on top of its quarter turns, to level a horizon or a stage. It zooms in just enough to keep the frame covered, and a drag snaps to level within 3px of 0°. The angle is part of `rotation`, so a 3° tilt after one turn left is `273`. The default controls include it; here it's on its own with Reset.

```tsx-live width=180
<ImageCrop src='/brand/photography/03.webp' aspectRatio={2}>
  <ImageCrop.Stage />
  <ImageCrop.Controls>
    <ImageCrop.Straighten />
    <ImageCrop.Reset />
  </ImageCrop.Controls>
</ImageCrop>
```

### Value

`onValueChange` gets the crop once the image loads, unless a `value` or `defaultValue` already fits, then once each drag, pinch, burst of scrolling, key press or button press ends, never on every frame. A new `src` starts centred unless a new `value` comes with it. `area` is in the image's own pixels and `percent` runs 0 to 100, both from the top left of the image once it's turned by `rotation`, in degrees clockwise. `zoom` is screen pixels per image pixel, so it changes with the crop area's size: save `area` or `percent`.

```tsx-live-noinline layout=stack gap=3
function EventImage() {
  const [crop, setCrop] = useState()
  const area = crop?.area

  return (
    <>
      <ImageCrop
        src='/brand/photography/08.webp'
        aspectRatio={2}
        label='Event image'
        onValueChange={setCrop}
      />
      <p className='text-display-ui-6 text-subtle'>
        {area
          ? `${Math.round(area.width)} × ${Math.round(area.height)}px from ${Math.round(area.x)}, ${Math.round(area.y)}`
          : 'Loading the image'}
      </p>
    </>
  )
}

render(<EventImage />)
```

### Composition

`ImageCrop.Stage` is the crop area. It's 4:3 and as wide as its container by default; set its size with `className`. `ImageCrop.Controls` is the pill over its bottom edge, with `ImageCrop.Zoom`, `ImageCrop.Rotate`, `ImageCrop.Straighten` and `ImageCrop.Reset` inside. Pass the parts you want, or leave the controls out.

```tsx-live width=180
<ImageCrop src='/brand/photography/08.webp' aspectRatio={2}>
  <ImageCrop.Stage className='aspect-video' />
  <ImageCrop.Controls>
    <ImageCrop.Zoom />
    <ImageCrop.Reset />
  </ImageCrop.Controls>
</ImageCrop>
```

## Guidelines

<Guidelines>

<Guideline title="Set the minimum the slot needs">
  <Guideline.Do
    code={`<ImageCrop aspectRatio={2} minWidth={1200} minHeight={600} />`}
  >
    Pass the smallest size the image shows at, so nobody can zoom into a crop
    that looks soft.
  </Guideline.Do>
  <Guideline.Dont code={`<ImageCrop aspectRatio={2} />`}>
    Don't leave zoom uncapped for an image with a size rule.
  </Guideline.Dont>
</Guideline>

<Guideline title="Save the area, not the zoom">
  <Guideline.Do code={`onValueChange={(crop) => save(crop.area)}`}>
    Store `area` or `percent`. Either one puts the crop back on any screen.
  </Guideline.Do>
  <Guideline.Dont code={`onValueChange={(crop) => save(crop.zoom)}`}>
    Don't store `zoom`, which depends on the crop area's size on screen.
  </Guideline.Dont>
</Guideline>

</Guidelines>

## Accessibility

- The crop area is a focusable group named by `label` (default "Crop image"), with a description that says how to move and zoom the image.
- In free-form, each corner is a button named for it ("Top left corner") with the role description "resize handle". Its arrow keys move the corner 10px, or 50px with Shift, so the crop grows as the corner moves out and shrinks as it moves in, while the opposite corner stays put. Alt is for a pointer only, since Alt and an arrow go back or forward a page in some browsers. The edges are for a pointer only, as the corners already resize both ways.
- The arrow keys move the image 10px, or 50px with Shift. `+` and `-` zoom in and out, and `R` turns the image 90° left. Each moves at once; a turn springs.
- The controls are a group named "Crop controls": two buttons and a slider named "Zoom", whose value reads as a percent of the zoom that covers the frame, then "Rotate left", a slider named "Straighten", and "Reset crop" once there's something to reset. Straighten runs from -45° to 45° and reads as "3 degrees right"; the arrows step 1°, or 5° with Shift, and Home and End go to 45° either way. Pressing Reset moves focus to the crop area. On a narrow crop the zoom buttons drop out, and the slider and keys still zoom.
- A plain scroll zooms only once the crop area has focus, so scrolling the page past it never zooms by accident. A trackpad pinch zooms whether or not it has focus.
- A polite live region says the crop's size, zoom, turn and straighten once a change settles, not on every frame.
- Focus shows a ring around the crop area. The frame, its grid, the size chip and the image are hidden from screen readers. With reduced motion on, springs end at once.
