Small Oztix illustrations in fixed brand colours, for empty states, dividers, and help content.

## Import

```tsx
import { NoteMusic, HighFive } from '@oztix/roadie-illustrations/spot'
```

Import the package's CSS after Roadie's, so Tailwind keeps the illustration colours:

```css
@import '@oztix/roadie-core/css';
@import '@oztix/roadie-illustrations/css';
```

Each illustration is its own module, so an app ships only the ones it imports. `@oztix/roadie-components/spot-illustrations` is deprecated. It has 12 of these, with older art.

## Examples

### Default

Every spot illustration is 48px square by default.

```tsx-live
<NoteMusic />
```

### Sizes

Size an illustration with a `size-*` class. Below 32px, use an icon instead.

```tsx-live layout=row gap=4
<NoteMusic className='size-8' />
<NoteMusic />
<NoteMusic className='size-16' />
<NoteMusic className='size-24' />
```

### Outline

`outline` draws a white sticker outline around the art, for busy or dark backgrounds. It's drawn from the art as it renders, 2px beyond it at 48px, so it always fits the square.

```tsx-live
<div className='grid grid-flow-col justify-start gap-4 rounded-xl bg-(--color-neutral-light-13) p-4'>
  <NoteMusic />
  <NoteMusic outline />
</div>
```

## Adding an illustration

Spot illustrations live in code, not in a design file. Each is an SVG source in `packages/illustrations/src/spot/svgs/`, one path per named layer:

| Layer     | Colour    | What it's for                                         |
| --------- | --------- | ----------------------------------------------------- |
| Shadow    | `#0091eb` | The extruded depth: the side faces                    |
| Face      | `#e1d1fb` | The object's front surface                            |
| Detail    | `#ffc3a8` | Secondary planes and accents, such as top faces       |
| Highlight | `#c2dffb` | Glass, screens, and shine                             |
| Stroke    | `#1a1f2b` | Every line, 0.5 wide with round ends, always on top   |

Draw in those colours, in any tool or by hand, and run `pnpm --filter @oztix/roadie-illustrations spot:convert` on the SVG. It merges each colour into its layer, cuts back lines that were hidden, shrinks art that would push the outline out of the box, and generates the component. It also counts the pixels that changed, so you can check nothing moved. The [package README](https://github.com/TicketSolutionsPtyLtd/roadie/tree/main/packages/illustrations) has the whole workflow.

## Guidelines

- Spot illustrations are decorative, so they're hidden from assistive tech. When one carries meaning, give it an `aria-label` and it becomes an image with that name.
- Their colours are fixed, so they look the same in dark mode.
