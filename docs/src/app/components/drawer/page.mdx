A surface that slides in from an edge and swipes away, built on Base UI's drawer primitive.

## Import

```tsx
import { Drawer } from '@oztix/roadie-components/drawer'
```

## Examples

### Default

A bottom sheet. `Drawer.Content` collapses the underlying `Portal`, `Backdrop`, `Viewport` and `Popup` into one element, and adds the grab handle because the swipe axis is vertical.

```tsx-live
<Drawer>
  <Drawer.Trigger render={<Button>Switch organisation</Button>} />
  <Drawer.Content>
    <Drawer.Header>
      <Drawer.Title>Organisations</Drawer.Title>
      <Drawer.Description>Switch the organisation you're working in.</Drawer.Description>
    </Drawer.Header>
    <Drawer.Body>
      <List emphasis='subtler'>
        {[
          { name: 'Paperbark Presents', members: 12, current: true },
          { name: 'The Corner Room', members: 4 },
          { name: 'Saltwater Sessions', members: 1 }
        ].map((org) => (
          <List.Item
            key={org.name}
            title={org.name}
            description={`${org.members} ${org.members === 1 ? 'member' : 'members'}`}
            current={org.current}
            chevron={false}
            leading={
              <IconTile intent='accent'>
                <BuildingsIcon weight='bold' />
              </IconTile>
            }
            trailing={org.current ? <CheckIcon weight='bold' className='size-5' /> : undefined}
          />
        ))}
      </List>
    </Drawer.Body>
  </Drawer.Content>
</Drawer>
```

`Drawer.Content` publishes `--content-inset`, so its header, body and footer share one horizontal inset — override the variable on `Drawer.Content` to change all three.

### Sides

`side` picks the edge, and with it the dismiss gesture — a `bottom` drawer swipes down, a `right` drawer swipes right. It is a single value, not a breakpoint list: Base UI owns the gesture in JavaScript, so the edge and the swipe have to agree.

```tsx-live
<div className='flex flex-wrap gap-3'>
  {['bottom', 'right', 'left', 'top'].map((side) => (
    <Drawer key={side} side={side}>
      <Drawer.Trigger render={<Button>{side}</Button>} />
      <Drawer.Content>
        <Drawer.Header>
          <Drawer.Title>From the {side}</Drawer.Title>
        </Drawer.Header>
        <Drawer.Body>
          <p>Swipe towards the {side} edge to dismiss.</p>
        </Drawer.Body>
      </Drawer.Content>
    </Drawer>
  ))}
</div>
```

### Emphasis

`emphasis` on the root sets how much the drawer takes over the page behind it. `normal` dims and blurs the page, `subtle` tints it and leaves it readable, and `subtler` leaves it clear. A click outside still closes the drawer at any level. A small bottom or top drawer defaults to `subtle`, because it peeks over its page. Every other drawer defaults to `normal`.

```tsx-live
<div className='flex flex-wrap gap-3'>
  {['normal', 'subtle', 'subtler'].map((emphasis) => (
    <Drawer key={emphasis} emphasis={emphasis}>
      <Drawer.Trigger render={<Button>{emphasis}</Button>} />
      <Drawer.Content size='sm'>
        <Drawer.Header>
          <Drawer.Title>Emphasis {emphasis}</Drawer.Title>
        </Drawer.Header>
        <Drawer.Body>
          <p>The page behind stays as visible as this level allows.</p>
        </Drawer.Body>
      </Drawer.Content>
    </Drawer>
  ))}
</div>
```

### Sizes

`size` sets the drawer's extent along its own axis: height for a bottom or top drawer, width for a side one. It defaults to `md`. For a bottom or top drawer it is a maximum, so short content still gives a short sheet, and long content scrolls in `Drawer.Body` between a fixed header and footer. A bottom or top drawer runs edge to edge on a phone. In a wider window it stops at `max-w-xl`, centred, and floats 0.5rem off its edge with every corner rounded, the same shape as the cart drawer.

```tsx-live-noinline
const holders = [
  'Alex Reid', 'Sam Okafor', 'Mia Chen', 'Noah Bell', 'Priya Nair',
  'Amelia Hart', 'Omar Haddad', 'Lily Tran', 'Archie Moss', 'Lucas Ferreira',
  'Sami Kaur', 'Nora Quinn', 'Xavier Lim', 'Dani Brooks', 'Layla Stone',
  'Ethan Cole', 'Grace Wu', 'Hamish Grant', 'Isla Murphy', 'Jack Doyle',
  'Kiara Singh', 'Leo Park', 'Maya Rossi', 'Nate Evans', 'Olive Clarke'
].map((name, index) => ({
  name,
  tickets: (index % 4) + 1,
  status: index === 0 ? 'Not shared' : index % 3 === 0 ? 'Sent' : 'Accepted'
}))

function Holders({ size }) {
  return (
    <Drawer>
      <Drawer.Trigger render={<Button>{size}</Button>} />
      <Drawer.Content size={size}>
        <Drawer.Header>
          <Drawer.Title>638 tickets</Drawer.Title>
          <Drawer.Description>Weekly Pass · Mon 3 to Fri 7 May</Drawer.Description>
        </Drawer.Header>
        <Drawer.Body>
          <List emphasis='subtler'>
            {holders.map((holder) => (
              <List.Item
                key={holder.name}
                title={holder.name}
                description={`${holder.tickets} ${holder.tickets === 1 ? 'ticket' : 'tickets'}`}
                chevron={false}
                leading={
                  <IconTile>
                    <UserIcon weight='bold' />
                  </IconTile>
                }
                trailing={
                  <Badge
                    size='sm'
                    intent={holder.status === 'Accepted' ? 'success' : holder.status === 'Sent' ? 'info' : undefined}
                  >
                    {holder.status}
                  </Badge>
                }

            ))}

        </Drawer.Body>
        <Drawer.Footer>
          <Drawer.Close render={<Button>Close</Button>} />
          <Button intent='accent' emphasis='strong'>Share tickets</Button>
        </Drawer.Footer>
      </Drawer.Content>
    </Drawer>
  )
}

render(
  <div className='flex flex-wrap gap-3'>

    <Holders size='md' />
    <Holders size='lg' />
  </div>
)
```

### Composition

The collapsed `Drawer.Content` covers the common case. Compose the parts directly when you need to reach the backdrop, the viewport or the popup separately.

```tsx-live
<Drawer side='right'>
  <Drawer.Trigger render={<Button>Compose the parts</Button>} />
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Viewport>
      <Drawer.Popup>
        <Drawer.Handle />
        <Drawer.Header>
          <Drawer.Title>Composed</Drawer.Title>
        </Drawer.Header>
        <Drawer.Body>
          <p>Portal, Backdrop, Viewport and Popup, wired by hand.</p>
        </Drawer.Body>
      </Drawer.Popup>
    </Drawer.Viewport>
  </Drawer.Portal>
</Drawer>
```

## Guidelines

<Guideline title='Long content scrolls in the body'>
  <Guideline.Do code={`<Drawer.Content>\n  <Drawer.Header>…</Drawer.Header>\n  <Drawer.Body>\n    {rows}\n  </Drawer.Body>\n</Drawer.Content>`}>
    `Drawer.Body` is the scroll region, and it tells the primitive that a drag
    starting there is a scroll rather than a dismiss. Long content belongs
    inside it.
  </Guideline.Do>
  <Guideline.Dont code={`<Drawer.Body>\n  <div className='overflow-y-auto'>\n    {rows}\n  </div>\n</Drawer.Body>`}>
    A second scroller inside the body competes with the swipe gesture, and the
    sheet stops tracking the thumb.
  </Guideline.Dont>
</Guideline>

<Guideline title='The handle belongs on the swipe edge'>
  <Guideline.Do code={`<Drawer side='bottom'>\n  <Drawer.Content>…</Drawer.Content>\n</Drawer>`}>
    `Drawer.Content` places it for you — on a bottom sheet it reads as the grab
    affordance iOS users reach for, and it is off by default where the swipe
    axis is horizontal.
  </Guideline.Do>
  <Guideline.Dont code={`<Drawer side='right'>\n  <Drawer.Content handle>…</Drawer.Content>\n</Drawer>`}>
    A horizontal swipe has no matching affordance in the platform, and a stray
    pill at the top of a side drawer reads as decoration.
  </Guideline.Dont>
</Guideline>

<Guideline title='Let the page show through only when it matters'>
  <Guideline.Do code={`<Drawer.Content size='sm'>\n  {/* the event stays readable behind the tickets */}\n</Drawer.Content>`}>
    Leave `emphasis` to its default. A small sheet over a page the user is
    still reading keeps that page legible, and a larger one takes their focus.
  </Guideline.Do>
  <Guideline.Dont code={`<Drawer.Backdrop className='bg-[oklch(0.1_0.04_250/0.3)]' />`}>
    Restating the scrim's colour to lighten it drifts from Roadie's the moment
    it changes. Set `emphasis` on the root instead.
  </Guideline.Dont>
</Guideline>

<Guideline title='One side, declared on the root'>
  <Guideline.Do code={`<Drawer side='right'>\n  <Drawer.Content>…</Drawer.Content>\n</Drawer>`}>
    The root sets the edge and the dismiss gesture together, and every part
    reads it from there. No part takes a `side` of its own, so the two can
    never disagree.
  </Guideline.Do>
  <Guideline.Dont code={`const side = isMobile ? 'bottom' : 'right'\n\n<Drawer side={side}>…</Drawer>\n\n// not a breakpoint list:\n<Drawer side={{ base: 'bottom', md: 'right' }} />`}>
    `side` is a single value, not a breakpoint list — Base UI owns the gesture
    in JavaScript. Pick it from your own media query in application code and
    pass the result.
  </Guideline.Dont>
</Guideline>

## Accessibility

- Base UI owns the focus trap, the return focus, the `Escape` handling and the `role='dialog'` wiring.
- `Drawer.Title` and `Drawer.Description` supply the accessible name and description. A drawer without a title has no name.
- `Drawer.Handle` is `aria-hidden` — the gesture it hints at is not the only way to dismiss, so it carries no semantics of its own.
- Enter and exit motion is transition-based and disabled under `prefers-reduced-motion: reduce`.
