A rich-text field that saves its content as an `EditorValue`.

## Import

```tsx
import { Editor } from '@oztix/roadie-editor/editor'
```

Add the editor's CSS after the components' CSS. It places the toolbar and
styles the placeholder and selection:

```css
@import '@oztix/roadie-core/css';
@import '@oztix/roadie-components/css';
@import '@oztix/roadie-editor/css';
```

## Presets

`preset` sets what the editor holds and saves. Each has its own page.

| Preset | Holds | Use it for |
| --- | --- | --- |
| [`basic`](/components/editor/basic-and-rich) (default) | Paragraphs, lists, bold, italic, underline, and links | A simple field, such as a ticket type's note |
| [`rich`](/components/editor/basic-and-rich#rich-preset) | The basic preset, plus headings, quotes, dividers, images, embeds, and tables | An event description |
| [`blocks`](/components/editor/blocks) | The rich preset, with an id on each block, the slash menu, drag, and custom blocks | A CMS page built from blocks |
| [`email`](/components/editor/email) | Sections, columns, buttons, images, spacers, merge tags, and conditions | An email design |

Every preset saves an `EditorValue`. [Saved content](/components/editor/saved-content)
covers storing it, `migrate`, rendering it with `/render`, and importing
existing HTML.

## Examples

### Default

The toolbar at the top of the editor holds the preset's controls, and each
control's tooltip shows its shortcut.

```tsx-live-prose
<Editor
  aria-label='Event description'
  placeholder='Tell people about the night'
/>
```

### Toolbar

The toolbar is a bar at the top of the editor, a size smaller than the text.
It scrolls away with a long description, and looks the same whether you're
editing or not, so the text never moves. On a phone or touch screen its
controls scroll sideways on one row when they don't fit.

```tsx-live-prose
<Editor
  aria-label='Event description'
  preset='rich'
  defaultValue={{
    version: 1,
    preset: 'rich',
    doc: {
      type: 'doc',
      content: [
        { type: 'heading', attrs: { level: 2 }, content: [{ type: 'text', text: 'Set times' }] },
        ...['Gates open, 11am', 'Ochre Kite, 12pm', 'Feathered Anchor Sessions, 1:15pm', 'The Jumbuck Strings, 2:30pm', 'Kazoo Hollow, 3:45pm', 'Saltbush Choir, 5pm', 'Last entry, 7pm', 'Headliner, 8:30pm', 'Curfew, 11pm'].map((set) => (
          { type: 'paragraph', content: [{ type: 'text', text: set }] }
        )),
        { type: 'heading', attrs: { level: 2 }, content: [{ type: 'text', text: 'Getting there' }] },
        { type: 'paragraph', content: [{ type: 'text', text: 'Shuttles leave Brisbane city every 20 minutes from 10am, and the last one back leaves at 11:30pm.' }] },
        { type: 'paragraph', content: [{ type: 'text', text: 'Bike racks are by the main gate. There’s no parking on site.' }] },
        { type: 'heading', attrs: { level: 2 }, content: [{ type: 'text', text: 'What to bring' }] },
        { type: 'paragraph', content: [{ type: 'text', text: 'A hat, sunscreen, and a refillable bottle. Water stations are by each stage.' }] }
      ]
    }
  }}
/>
```

### Selection menu

Add `Editor.BubbleMenu` among the parts to show Bold, Italic, Underline and
Link above selected text, close to it on a phone or in a long document. It
shows while text is selected and the editor has focus, and hides when the
selection collapses, on a selected image or embed, while the link editor is
open, and when the editor is read-only or disabled. Children go after the
preset's controls, as in `Editor.Toolbar`.

```tsx-live-prose
<Editor
  aria-label='Event description'
  defaultValue={{
    version: 1,
    preset: 'basic',
    doc: {
      type: 'doc',
      content: [
        { type: 'paragraph', content: [{ type: 'text', text: 'Ochre Kite Weekender opens at Jumbuck Orchard Park on Saturday.' }] },
        { type: 'paragraph', content: [{ type: 'text', text: 'Select a few words to format them from the menu.' }] }
      ]
    }
  }}
>
  <Editor.Toolbar />
  <Editor.Content />
  <Editor.BubbleMenu />
</Editor>
```

### Emphasis

`emphasis` sets the frame. The toolbar takes its own
[emphasis](#toolbar-emphasis), so it's the same in each.

| Emphasis           | Frame                                   | Use it for                                                |
| ------------------ | --------------------------------------- | --------------------------------------------------------- |
| `normal` (default) | A field's border, fill, and focus ring  | A form, beside other fields                               |
| `subtle`           | A tint with no border, and a focus ring | A form on a busy surface, where a border adds noise       |
| `subtler`          | None: the content sits on the page      | Content edited in place, such as an event page's sections |

```tsx-live-prose layout=stack gap=2
<Editor aria-label='Normal emphasis' emphasis='normal' placeholder='Normal emphasis' />
<Editor aria-label='Subtle emphasis' emphasis='subtle' placeholder='Subtle emphasis' />
```

#### Subtler

`emphasis='subtler'` drops the border, fill, and padding, so the text lines up
with the page around it and editing looks like reading. The caret shows
where focus is.
Its skeleton is lines of text, not a box.

```tsx-live-prose layout=stack gap=2
<h2 id='about-the-event' className='text-display-ui-4 text-strong'>
  About the event
</h2>
<Editor
  aria-labelledby='about-the-event'
  emphasis='subtler'
  preset='rich'
  defaultValue={{
    version: 1,
    preset: 'rich',
    doc: {
      type: 'doc',
      content: [
        {
          type: 'paragraph',
          content: [
            { type: 'text', marks: [{ type: 'bold' }], text: 'Ochre Kite Weekender' },
            { type: 'text', text: ' returns to Jumbuck Orchard Park, Brisbane, for two days in the sun.' }
          ]
        },
        {
          type: 'bulletList',
          content: [
            { type: 'listItem', content: [{ type: 'paragraph', content: [{ type: 'text', text: 'Gates open 11am' }] }] },
            { type: 'listItem', content: [{ type: 'paragraph', content: [{ type: 'text', text: 'Shuttles from Brisbane city every 20 minutes' }] }] }
          ]
        }
      ]
    }
  }}
/>
```

An invalid `subtler` editor has no border to turn red, so it draws a danger
edge on its start side, just outside the text, and `Field.ErrorText` says
what's wrong. Give it room at the start: a container that clips its overflow
hides the edge. A disabled one dims as a disabled field does.

#### Toolbar emphasis

`Editor.Toolbar` takes [Toolbar's `emphasis`](/components/toolbar#emphasis) for its bar, the same on every screen and
whether you're editing or not. It's independent of the editor's own `emphasis`. To
change it, pass the parts yourself:

| Emphasis           | Bar                                      | Use it for                                   |
| ------------------ | ---------------------------------------- | -------------------------------------------- |
| `normal` (default) | A visible border on the normal surface   | Most editors, in a form or on the page       |
| `subtle`           | A tint with no border                    | A busy surface, where a border adds noise    |
| `subtler`          | No surface, just the controls            | A quiet bar, such as over a `subtler` editor |
| `raised`           | A translucent raised surface             | An editor on a tinted surface                |
| `floating`         | A translucent surface with a deep shadow | A bar that should read as above the content  |

```tsx-live-prose layout=stack gap=2
<Editor aria-label='Subtler toolbar' placeholder='Subtler toolbar'>
  <Editor.Toolbar emphasis='subtler' />
  <Editor.Content />
</Editor>
<Editor aria-label='Raised toolbar' placeholder='Raised toolbar'>
  <Editor.Toolbar emphasis='raised' />
  <Editor.Content />
</Editor>
```

### Sizes

`size` sets the body and heading sizes to match `Prose`, so editing looks
like the published page.

```tsx-live-prose layout=stack gap=2
<Editor aria-label='Small' size='sm' placeholder='Small' />
<Editor aria-label='Medium' size='md' placeholder='Medium (default)' />
<Editor aria-label='Large' size='lg' placeholder='Large' />
```

### Controlled

`onValueChange` gets the whole `EditorValue` on each change. Save it as JSON,
never as HTML, and pass a stored value through
[`migrate`](/components/editor/saved-content#migrate) before it goes back in.
The editor takes its preset from the value. A `preset` prop that differs reads
the value into that preset, keeping the text of what it can't hold.

```tsx-live-prose-noinline
function DescriptionEditor() {
  const [value, setValue] = useState()
  return (
    <Editor
      aria-label='Event description'
      placeholder='Tell people about the night'
      value={value}
      onValueChange={setValue}
    />
  )
}

render(<DescriptionEditor />)
```

### Composition

#### Field

In a `Field`, the editor is named by `Field.Label` and described by
`Field.HelperText`, or by `Field.ErrorText` while the field is invalid. It
takes `invalid`, `required`, and `disabled` from the field.

```tsx-live layout=stack
{/* Default */}
<Field>
  <Field.Label>Event description</Field.Label>
  <Editor placeholder='Tell people about the night' />
  <Field.HelperText>Shown on the event page, under the lineup.</Field.HelperText>
</Field>
{/* Invalid */}
<Field invalid required>
  <Field.Label showIndicator>Event description</Field.Label>
  <Editor placeholder='Tell people about the night' />
  <Field.ErrorText>Add a description so people know what's on.</Field.ErrorText>
</Field>
```

#### Forms

`name` adds a hidden input that holds the `EditorValue` as JSON, so a native
form submits it. A disabled editor leaves it out, as a disabled input does.

```tsx
<form action='/events/ochre-kite-weekender' method='post'>
  <Field>
    <Field.Label>Event description</Field.Label>
    <Editor name='description' defaultValue={savedDescription} />
  </Field>
  <Button type='submit'>Save</Button>
</form>
```

#### Custom controls

With no children, `Editor` renders `Editor.Toolbar` then `Editor.Content`.
Pass them yourself to add controls: `Editor.Toolbar` renders the preset's
controls, then its children. A `Toolbar.Button` child joins the toolbar's
arrow order, and `useEditorContext()` gives it the editor to run commands on.

```tsx-live-prose-noinline
function DoorsTimeControl() {
  const { editor } = useEditorContext()
  return (
    <Toolbar.Button
      onClick={() =>
        editor?.chain().focus().insertContent('Doors open 7pm. ').run()
      }
    >
      Add doors time
    </Toolbar.Button>
  )
}

render(
  <Editor aria-label='Event description' placeholder='Tell people about the night'>
    <Editor.Toolbar>
      <Toolbar.Separator />
      <DoorsTimeControl />
    </Editor.Toolbar>
    <Editor.Content />
  </Editor>
)
```

## Guidelines

- The editor's code loads after the page, so `Editor` shows a skeleton the
  height of the empty editor until then, and always on the server. Call `preloadEditor()`
  on the hover or focus that leads to an editor to start loading it sooner.
- Put the editor in a `Field` with a `Field.Label`. Outside one, label it
  with `aria-label` or `aria-labelledby`; a `<label for>` can't name editable
  content.
- Add a custom control only for something the preset can't do. A preset's
  controls come with its schema, so each one works on what the editor can
  save.

## Accessibility

- The editable area is a `textbox` with `aria-multiline`. In a `Field` it's
  named by `Field.Label` through `aria-labelledby`, unless `Editor` has its
  own `aria-label` or `aria-labelledby`, and described by the helper or error
  text through `aria-describedby`.
- An invalid or required field sets `aria-invalid` or `aria-required`. A
  read-only editor sets `aria-readonly`, and a disabled one `aria-disabled`.
- A `subtler` editor has no focus ring: the caret shows
  focus. While invalid it shows a danger edge at its start, beside
  `aria-invalid` and the error text.
- Tab moves into and out of the editor. In a list, Tab nests an item under
  the one before it and Shift+Tab lifts it back out.
- The toolbar is a `toolbar` named Formatting, with `aria-controls` set to
  the editable area. It takes one Tab stop, and the arrow keys move between its
  controls, scrolling the one with focus into view on a phone. Bold, italic, underline,
  link, and the lists are toggles that report
  `aria-pressed` for the text at the caret. Undo and Redo are disabled when
  there's nothing to undo or redo, and stay focusable.
- The selection menu is a `toolbar` named Selection formatting, with the same
  keys as Formatting. It shows only while text is selected and the editor has
  focus. Alt+F10 moves focus to its first control while it shows, and Escape
  moves focus back to the selection.
- Each control carries its shortcut in `aria-keyshortcuts`.
- The link editor is a popover by the selection, with an input named Link. It
  takes focus when it opens, Enter or the Save link button saves, and Escape
  or the Close button closes it and puts the caret back where it was. A refused
  address shows its error under the row, and focus stays in the input.
- Each popover's icon buttons are named for what they do: Save link, Embed
  link, Save alt text, Remove link, and Close. A check with nothing to save is
  disabled but keeps its Tab stop.

| Keys | Action |
| --- | --- |
| `Mod+B` | Bold |
| `Mod+I` | Italic |
| `Mod+U` | Underline |
| `Mod+K` | Add, change, or remove a link |
| `Mod+Shift+8` | Bulleted list |
| `Mod+Shift+7` | Numbered list |
| `Mod+Z` | Undo |
| `Mod+Shift+Z` | Redo |
| `Shift+Enter` | Line break |
| `Alt+F10` | Move focus to the toolbar's first enabled control, the selection menu's while it shows, a selected image's, embed's, or spacer's first action, the first action of the button or columns holding the caret, or in a table its first table action |
| `Escape` | In a toolbar, move focus back to the text, where the caret was, or to the selected image or embed |

`Mod` is `⌘` on Apple devices and `Ctrl` elsewhere, and `Alt` is `⌥` on
Apple devices.

The [Basic and Rich](/components/editor/basic-and-rich#accessibility) and
[Email](/components/editor/email#accessibility) pages list the keys their
presets add.

## Hooks

### useEditorContext

```tsx
function useEditorContext(): { editor: Editor | null }
```

Returns the Tiptap `Editor` of the nearest `Editor`, for a custom control in
`Editor.Toolbar` or elsewhere among its children. `editor` is null for a moment after the editor's code
loads, until it mounts. It throws outside an `Editor`.
