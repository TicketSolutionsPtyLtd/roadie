A searchable list of pages and actions in a dialog.

## Import

```tsx
import { CommandPalette } from '@oztix/roadie-components/command-palette'
```

## Examples

### Default

Pass the commands as `items`, and render each one in the list's child
function. A command with `href` is a link; one with `onSelect` runs it.
Either way, picking it closes the palette. This example opens from its own
button, with `open` and `onOpenChange`, and `shortcut={false}`, as this site's
palette has the shortcut: press ⌘K, or Ctrl+K, to try that one.
`onOpenChange` says why it changed: `'item-press'` when a command was picked,
`'shortcut'` for the keys, and Base UI's reasons, such as `'escape-key'`,
otherwise.

```tsx-live-noinline
function Search() {
  const [open, setOpen] = useState(false)
  const commands = [
    { label: 'Events', href: '#events' },
    { label: 'Orders', href: '#orders' },
    { label: 'Settings', href: '#settings', keywords: ['preferences'] },
    { label: 'New event', onSelect: () => {} },
  ]

  return (
    <>
      <Button onClick={() => setOpen(true)}>Search</Button>
      <CommandPalette open={open} onOpenChange={setOpen} shortcut={false} items={commands}>
        <CommandPalette.Input placeholder='Search pages and actions' />
        <CommandPalette.List>
          {(command) => (
            <CommandPalette.Item
              key={command.label}
              value={command}
              href={command.href}
              onSelect={command.onSelect}
            >
              {command.label}
            </CommandPalette.Item>
          )}
        </CommandPalette.List>
        <CommandPalette.Empty>No pages or actions match</CommandPalette.Empty>
      </CommandPalette>
    </>
  )
}

render(<Search />)
```

### With the shortcut and a trigger

Left uncontrolled, a palette opens with ⌘K on a Mac, or Ctrl+K elsewhere, from
anywhere on the page. `CommandPalette.Trigger` opens it from a button that
shows that shortcut, and can sit anywhere, such as an app's header. This
site's Search button is one.

```tsx
<>
  <CommandPalette.Trigger />
  <CommandPalette items={commands}>
    <CommandPalette.Input placeholder='Search pages and actions' />
    <CommandPalette.List>
      {(command) => (
        <CommandPalette.Item key={command.label} value={command} href={command.href}>
          {command.label}
        </CommandPalette.Item>
      )}
    </CommandPalette.List>
  </CommandPalette>
</>
```

### States

A command with `disabled` stays in the list, dimmed, and can't be picked.
When nothing matches, `CommandPalette.Empty` shows its text.

```tsx-live-noinline
function SearchStates() {
  const [open, setOpen] = useState(false)
  const commands = [
    { label: 'Events', href: '#events' },
    { label: 'Payouts', disabled: true },
  ]

  return (
    <>
      <Button onClick={() => setOpen(true)}>Search</Button>
      <CommandPalette open={open} onOpenChange={setOpen} shortcut={false} items={commands}>
        <CommandPalette.Input placeholder='Search pages and actions' />
        <CommandPalette.List>
          {(command) => (
            <CommandPalette.Item
              key={command.label}
              value={command}
              href={command.href}
              disabled={command.disabled}
            >
              {command.label}
            </CommandPalette.Item>

        <CommandPalette.Empty>No pages or actions match</CommandPalette.Empty>

    </>
  )
}

render(<SearchStates />)
```

### Composition

#### With groups, icons and shortcuts

Pass groups as `items`, each with its own `items`, and render each group's
commands through `CommandPalette.Collection`. `icon` goes before a label and
`shortcut` after it, as a hint.

```tsx-live-noinline
function GroupedSearch() {
  const [open, setOpen] = useState(false)
  const groups = [
    {
      label: 'Go to',
      items: [
        { label: 'Events', href: '#events', icon: <TicketIcon weight='bold' className='size-4' /> },
        { label: 'Orders', href: '#orders', icon: <ShoppingCartIcon weight='bold' className='size-4' /> },
      ],
    },
    {
      label: 'Actions',
      items: [
        { label: 'New event', shortcut: ['mod', 'e'], icon: <PlusIcon weight='bold' className='size-4' /> },
        { label: 'Invite teammate', icon: <UsersIcon weight='bold' className='size-4' /> },
      ],
    },
  ]

  return (
    <>
      <Button onClick={() => setOpen(true)}>Search</Button>
      <CommandPalette open={open} onOpenChange={setOpen} shortcut={false} items={groups}>
        <CommandPalette.Input placeholder='Search pages and actions' />
        <CommandPalette.List>
          {(group) => (
            <CommandPalette.Group key={group.label} items={group.items}>
              <CommandPalette.GroupLabel>{group.label}</CommandPalette.GroupLabel>
              <CommandPalette.Collection>
                {(command) => (
                  <CommandPalette.Item
                    key={command.label}
                    value={command}
                    href={command.href}
                    icon={command.icon}
                    shortcut={command.shortcut}
                  >
                    {command.label}
                  </CommandPalette.Item>
                )}
              </CommandPalette.Collection>
            </CommandPalette.Group>
          )}
        </CommandPalette.List>
        <CommandPalette.Empty>No pages or actions match</CommandPalette.Empty>
      </CommandPalette>
    </>
  )
}

render(<GroupedSearch />)
```

#### With type tabs and a key footer

`CommandPalette.Scopes` narrows the list to one type. Give a command, or its
group, a `scope`, and add a `CommandPalette.Scope` with that value; All comes
first and shows everything. The left and right arrows change type when the
search is empty, or the caret is at that end of it. `CommandPalette.Footer`
holds `CommandPalette.Hint`s that remind people of the keys, and hides on a
phone.

```tsx-live-noinline
function TypedSearch() {
  const [open, setOpen] = useState(false)
  const groups = [
    {
      label: 'Events',
      scope: 'events',
      items: [{ label: 'Velvet Dingo Fest' }, { label: 'Lampshade Disco' }],
    },
    {
      label: 'Venues',
      scope: 'venues',
      items: [{ label: 'Kazoo Hollow Room' }, { label: 'Iguana Teapot Hall' }],
    },
  ]

  return (
    <>
      <Button onClick={() => setOpen(true)}>Search</Button>
      <CommandPalette open={open} onOpenChange={setOpen} shortcut={false} items={groups}>
        <CommandPalette.Input placeholder='Search events and venues' />
        <CommandPalette.Scopes>
          <CommandPalette.Scope value='events'>Events</CommandPalette.Scope>
          <CommandPalette.Scope value='venues'>Venues</CommandPalette.Scope>
        </CommandPalette.Scopes>
        <CommandPalette.List>
          {(group) => (
            <CommandPalette.Group key={group.label} items={group.items}>
              <CommandPalette.GroupLabel>{group.label}</CommandPalette.GroupLabel>
              <CommandPalette.Collection>
                {(command) => (
                  <CommandPalette.Item key={command.label} value={command}>
                    {command.label}
                  </CommandPalette.Item>
                )}
              </CommandPalette.Collection>
            </CommandPalette.Group>
          )}
        </CommandPalette.List>
        <CommandPalette.Empty>Nothing matches</CommandPalette.Empty>
        <CommandPalette.Footer>
          <CommandPalette.Hint shortcut={['escape']}>Close</CommandPalette.Hint>
          <CommandPalette.Hint shortcut={['arrowleft', 'arrowright']}>Change type</CommandPalette.Hint>
        </CommandPalette.Footer>
      </CommandPalette>
    </>
  )
}

render(<TypedSearch />)
```

## Guidelines

<Guidelines>

<Guideline title='Name commands as places or actions'>
  <Guideline.Do>
    Use the page's name for a place, such as "Orders", and a verb for an
    action, such as "Invite teammate".
  </Guideline.Do>
  <Guideline.Dont>
    Don't add "Go to" or "Open" to every command. A group label says it once.
  </Guideline.Dont>
</Guideline>

<Guideline title='Match what people type'>
  <Guideline.Do>
    Add `keywords` for the other words people use, such as "preferences" for
    Settings.
  </Guideline.Do>
  <Guideline.Dont>
    Don't put keywords in the label to make it match.
  </Guideline.Dont>
</Guideline>

</Guidelines>

### Shortcut

The palette binds ⌘K on Apple platforms and Ctrl+K elsewhere. Pass another key
list to `shortcut`, such as `['mod', 'p']`, or `false` for none. Give one
palette per page a shortcut: `CommandPalette.Trigger` opens that one, and a
second palette with a shortcut takes it over, with a warning in development.
A field that handles the same keys itself, such as the editor's link
shortcut, calls `preventDefault`, and the palette leaves the key to it.

### Matching

Typing ranks the commands: an exact match first, then labels that start with
the text, then labels with a word that starts with it, then labels that
contain it. A command that matches only through its `keywords` comes after
those. Case and accents don't count. Groups keep their order, and their
commands are ranked within them. Each opening starts with an empty search.

### On a phone

Below the `sm` breakpoint the palette fills the screen, with the input at the
top and a Close button beside it. `CommandPalette.Input` draws that Close, so
keep it as the palette's input. It's the same list, keys and screen reader
flow at every size.

## Accessibility

- The palette is a modal dialog named "Search and commands"; set `label` to
  name it otherwise. Focus starts in the input and stays in the dialog.
- The input is a combobox named "Search" (`aria-label` overrides it). It
  points `aria-activedescendant` at the highlighted command, so screen readers
  read it as the arrows move.
- The first command is highlighted, so **Enter** picks it straight away. The
  **arrow keys** move the highlight and wrap at either end.
- With `CommandPalette.Scopes`, the **left and right arrows** change type
  from an empty search, or from the caret at that end of it. The tabs are a
  toggle group named "Type", reachable with **Tab**.
- **Escape** closes the palette, and focus goes back to what opened it. The
  shortcut closes it too.
- `CommandPalette.Trigger` carries the shortcut in `aria-keyshortcuts`, so
  screen readers announce it; the keycaps are visual.
- A command with `href` is a link, so it opens in a new tab with a modified
  click, as any link does.
