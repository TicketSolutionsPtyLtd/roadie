A scrolling column in an app frame, with a sticky header and footer and a place
in the stack when panes share a screen.

## Import

```tsx
import { Pane } from '@oztix/roadie-components/pane'
```

## How it works

- A pane is a `<section>` with its own surface and its own scroll. The page
  never scrolls.
- `Pane.Header` and `Pane.Footer` stay put while the body scrolls between them.
- A pane works on its own. Inside [`Navigator.Content`](/components/navigator),
  panes become columns where there is room and a stack where there isn't. Two
  panes join one stack even when separate routes render them, which is what
  [App shell](/foundations/app-shell) builds on.
- Each pane has a `depth`. The deepest `current` pane is the top, and it is
  always on screen.

## Examples

### Default

A pane in a box. Scroll it to see the body move under the sticky header.

```tsx-live
<div className='h-80 rounded-2xl bg-sunken p-3'>
  <Pane role='detail' className='h-full'>
    <Pane.Header>
      <Pane.Title>Midnight Frequency</Pane.Title>
    </Pane.Header>
    <List>
      <List.Item title='General admission' subtitle='$68.00 · on sale' chevron />
      <List.Item title='Early bird' subtitle='$54.00 · sold out' chevron />
      <List.Item title='VIP booth' subtitle='$180.00 · 6 remaining' chevron />
      <List.Item title='Group of 6' subtitle='$360.00 · on sale' chevron />
      <List.Item title='Accessible seating' subtitle='$68.00 · on sale' chevron />
      <List.Item title='Companion' subtitle='$0.00 · on request' chevron />
      <List.Item title='Doors' subtitle='7:00 pm' />
      <List.Item title='Support act' subtitle='The Paper Kites' />
    </List>
  </Pane>
</div>
```

The `List` declares no padding. The pane pads its content by
`--content-inset`, and the header, search and footer read the same value, so
the title and body text line up. A `subtler` `List` pulls its rows back out by
their own padding, so row backgrounds run wider than the text.

It sits straight on the frame behind it.

### Composition

`Pane.Header` has a top row, with Back at the start and `Pane.Actions` at the
end. The title, a `Pane.Search` and anything else sit beneath it at full width.
`Pane.Footer` is the same material at the bottom of the pane.

```tsx-live-noinline
function Composed() {
  const [query, setQuery] = useState('')
  const rows = [
    'General admission',
    'Early bird',
    'VIP booth',
    'Group of 6',
    'Accessible seating',
    'Companion'
  ]
  const shown = rows.filter((row) =>
    row.toLowerCase().includes(query.toLowerCase())
  )
  return (
    <div className='h-96 rounded-2xl bg-sunken p-3'>
      <Pane role='detail' className='h-full'>
        <Pane.Header onBack={() => setQuery('')}>
          <Pane.Title>Ticket types</Pane.Title>
          <Pane.Actions>
            <Button intent='accent' emphasis='strong'>
              Publish
            </Button>
          </Pane.Actions>
          <Pane.Search
            value={query}
            onValueChange={setQuery}
            placeholder='Filter ticket types'
          />
        </Pane.Header>
        <List>
          {shown.map((row) => (
            <List.Item key={row} title={row} chevron />
          ))}
        </List>
        {shown.length === 0 ? (
          <p className='py-3 text-sm text-subtle'>No matches</p>
        ) : null}
        <Pane.Footer>
          <Button size='sm' emphasis='normal'>
            Add ticket type
          </Button>
        </Pane.Footer>
      </Pane>
    </div>
  )
}
render(<Composed />)
```

- Leave controls in `Pane.Actions` at their default size.
- `Pane.Search` is the search field a searchable `Navigator.Secondary` uses. It
  doesn't filter anything, so `.filter()` your own rows. Cancel shows while the
  field has focus.
- This pane shows Back because it has an `onBack` and nothing sits to its left.
  Inside `Navigator.Content`, the columns decide. See
  [Back and Close](#back-and-close).

### Titles

`Pane.Title` renders a large heading and a compact title. As the pane scrolls,
the compact title fades in, centred in the header's top row, and the header
takes a shadow. Tapping the compact title scrolls the pane back to the top.
`Pane.Title` must be a direct child of `Pane.Header`, because the compact title
places itself in the header's grid.

#### Body title

`Pane.BodyTitle` puts the heading in the scrolling body instead. Leave
`Pane.Header` without a title, and it shows the same compact title once the
body title scrolls away. This is the recommended option, because the header
keeps one height throughout.

```tsx-live
<div className='h-80 rounded-2xl bg-sunken p-3'>
  <Pane role='detail' className='h-full'>
    <Pane.Header />
    <div className='grid gap-3 pb-4'>
      <Pane.BodyTitle>Midnight Frequency</Pane.BodyTitle>
      <p className='text-subtle'>Sat 14 Feb · The Tivoli · 60 remaining</p>
    </div>
  </Pane>
</div>
```

- It defaults to `text-display-ui-3`. Pass another `text-display-*` class to
  resize it.
- It takes the pane's content inset, like the rest of the body.
- Don't declare both. If the header has a `Pane.Title`, that title wins and
  `Pane.Header` warns in development.

### Columns and stacking

Inside `Navigator.Content`, panes sit side by side where there is room and stack
where there isn't. `Navigator.Content` measures its own width, not the window's.

| Content width | Columns |
| --- | --- |
| Below 46.25rem | One. Only the top pane shows. |
| From 46.25rem | Two, with the root beside a detail |
| From 55.25rem | Two, with a detail beside a deeper pane |
| From 76rem | Three, starting from the root |
| From 81rem | Three, starting from a detail |

A row never shows more columns than its stack has levels. The right-most column
fills, at least 28rem wide. Each column to its left takes a parent track:

- the root takes 16 to 24rem, or 20 to 24rem with three columns;
- a detail takes 25 to 30rem.

The panes behind the top fill the remaining columns nearest first, so the
left-most pane drops first. In the stack, moving between depths slides. Columns
don't animate. See [Roles](#roles) for each role's default depth, and declare
`depth={2}` on a sub-detail.

Select a row, then resize the window. The same code is a side-by-side reveal
where two columns fit and a push where they don't.

```tsx-live-noinline
function Stacking() {
  const [selected, setSelected] = useState(null)
  const events = [
    { id: 'midnight', title: 'Midnight Frequency', subtitle: '1,240 sold · 60 remaining' },
    { id: 'sunset', title: 'Sunset Sounds', subtitle: '820 sold · 180 remaining' },
    { id: 'neon', title: 'Neon Dusk', subtitle: '540 sold · 460 remaining' },
    { id: 'harbour', title: 'Harbour Lights', subtitle: '2,010 sold · sold out' }
  ]
  const event = events.find((e) => e.id === selected)
  return (
    <div className='h-[30rem] overflow-hidden rounded-2xl border border-subtle'>
      <Navigator className='h-full'>
        <Navigator.Content>
          <Pane role='list' aria-label='Events'>
            <Pane.Header>
              <Pane.Title>Events</Pane.Title>
            </Pane.Header>
            <List>
              {events.map((e) => (
                <List.Item
                  key={e.id}
                  title={e.title}
                  subtitle={e.subtitle}
                  chevron
                  current={selected === e.id}
                  onClick={() => setSelected(e.id)}
                />
              ))}
            </List>
          </Pane>
          <Pane role='detail' current={event != null} aria-label='Event'>
            <Pane.Header onBack={() => setSelected(null)} backLabel='Events'>
              <Pane.Title>{event ? event.title : 'Nothing selected'}</Pane.Title>
            </Pane.Header>
            <div className='grid gap-3 pb-4'>
              <p className='text-subtle'>
                {event ? event.subtitle : 'Pick an event from the list.'}
              </p>
            </div>
          </Pane>
        </Navigator.Content>
      </Navigator>
    </div>
  )
}
render(<Stacking />)
```

### Roles

`role` sets a pane's default depth and when it gives up its column.

| Role | Default depth | Column |
| --- | --- | --- |
| `list` | 0 | The root |
| `detail` | 1 | Under the root |
| `inspector` | None | A fixed 14rem column outside the stack. It shows only when every level of the stack fits beside it. |

When the inspector's column is hidden, give people another way in. Put a
[`Drawer`](/components/drawer) in the detail pane's `Pane.Actions`, and Base UI
handles dismissal, focus, Escape and the scrim. The `pane-inspector-yielded:`
variant shows its trigger only while the column is hidden.

```tsx-live-noinline
function Roles() {
  const [open, setOpen] = useState(false)
  const [showDetail, setShowDetail] = useState(true)
  const tiers = [
    { title: 'General admission', subtitle: '$68.00 · on sale' },
    { title: 'Early bird', subtitle: '$54.00 · sold out' },
    { title: 'VIP booth', subtitle: '$180.00 · 6 remaining' },
    { title: 'Group of 6', subtitle: '$360.00 · on sale' },
    { title: 'Accessible seating', subtitle: '$68.00 · on sale' }
  ]
  return (
    <div className='h-[30rem] overflow-hidden rounded-2xl border border-subtle'>
      <Navigator className='h-full'>
        <Navigator.Content>
          <Pane role='list' aria-label='Events'>
            <Pane.Header>
              <Pane.Title>Events</Pane.Title>
            </Pane.Header>
            <List>
              <List.Item title='Midnight Frequency' subtitle='60 remaining' current onClick={() => setShowDetail(true)} />
              <List.Item title='Sunset Sounds' subtitle='180 remaining' />
              <List.Item title='Neon Dusk' subtitle='460 remaining' />
              <List.Item title='Harbour Lights' subtitle='sold out' />
            </List>
          </Pane>
          <Pane role='detail' aria-label='Midnight Frequency' current={showDetail}>
            <Pane.Header onBack={() => setShowDetail(false)}>
              <Pane.Title>Midnight Frequency</Pane.Title>
              <Pane.Actions>
                <Drawer open={open} onOpenChange={setOpen} side='bottom'>
                  <Drawer.Trigger
                    render={
                      <IconButton
                        aria-label='Event details'
                        emphasis='normal'
                        className='pane-inspector-yielded:inline-flex hidden'
                      >
                        <InfoIcon weight='bold' className='size-5' />
                      </IconButton>
                    }
                  />
                  <Drawer.Content aria-label='Event details'>
                    <Drawer.Body className='py-4'>
                      <List emphasis='subtler'>
                        <List.Item title='Venue' subtitle='The Tivoli' />
                        <List.Item title='Doors' subtitle='7:00 pm' />
                        <List.Item title='Capacity' subtitle='1,300' />
                      </List>
                    </Drawer.Body>
                  </Drawer.Content>
                </Drawer>
              </Pane.Actions>
            </Pane.Header>
            <List>
              {tiers.map((tier) => (
                <List.Item key={tier.title} title={tier.title} subtitle={tier.subtitle} chevron />
              ))}
            </List>
          </Pane>
          <Pane role='inspector' emphasis='subtler' aria-label='Event details'>
            <Pane.Header>
              <Pane.Title>Details</Pane.Title>
            </Pane.Header>
            <List emphasis='subtler'>
              <List.Item title='Venue' subtitle='The Tivoli' />
              <List.Item title='Doors' subtitle='7:00 pm' />
              <List.Item title='Capacity' subtitle='1,300' />
            </List>
          </Pane>
        </Navigator.Content>
      </Navigator>
    </div>
  )
}
render(<Roles />)
```

### Back and Close

The header's leading cell shows at most one button, based on where the pane
sits in the columns.

| The pane is | It shows |
| --- | --- |
| The root, at depth 0 | Nothing |
| The left-most visible pane, with its parent dropped | Back, to that parent |
| The top pane, with its parent visible beside it | Close |
| A middle column | Nothing |
| A placeholder detail not yet reached | Nothing |
| An inspector | Nothing |

On a phone the top pane is also the left-most, so it gets Back. Both buttons go
one level up. `backHref` is the target for both:

```tsx
<Pane role='detail' depth={2} current>
  <Pane.Header backHref='/tickets/glamping' backLabel='Glamping'>
    <Pane.Title>Sam Okafor</Pane.Title>
  </Pane.Header>
</Pane>
```

`onBack` does the same as a handler. `onClose` overrides it for Close alone:

```tsx
<Pane.Header onBack={goUp} onClose={closeDetail}>
```

- Back is always the round caret button. `backLabel` names it for assistive
  tech, as "Back to Glamping", without showing on screen.
- Under a section's generated list, Navigator gives the depth-1 pane its section
  route and label, so you declare nothing.
- Nothing shows until you give a target, because Roadie can't close a pane it
  doesn't own.
- The root pane never shows Close, even if you pass the same handler to every
  pane.

## Guidelines

<Guideline title='Declaration order is stack depth'>
  <Guideline.Do code={`<Navigator.Content>\n  <Pane role='list' />\n  <Pane role='detail' current={selected != null} />\n</Navigator.Content>`}>
    Author panes shallowest first. Once panes mount, document order is depth.
    The server render uses `depth`, which defaults from `role`, so declare
    `depth={2}` on a sub-detail.
  </Guideline.Do>
  <Guideline.Dont code={`<Navigator.Content>\n  <Pane role='detail' current />\n  <Pane role='list' />\n</Navigator.Content>`}>
    Author panes out of depth order. The pane parks on the wrong side, so the
    push slides in from the left and the pop from the right.
  </Guideline.Dont>
</Guideline>

<Guideline title='Give the root route a placeholder detail'>
  <Guideline.Do code={`<Navigator.Content>\n  <Pane role='list' />\n  <Pane role='detail' current={event != null}>\n    {event ? <EventDetail /> : <EmptyState title='No event selected' />}\n  </Pane>\n</Navigator.Content>`}>
    Render the detail pane on the root route too, like Mail's "No message
    selected". The row then reads as a list beside an empty detail.
  </Guideline.Do>
  <Guideline.Dont code={`<Navigator.Content>\n  <Pane role='list' />\n  {event ? <Pane role='detail' current /> : null}\n</Navigator.Content>`}>
    Mount the detail only once something is selected. The list fills the row
    alone, then jumps to a parent track when the detail appears.
  </Guideline.Dont>
</Guideline>

<Guideline title='Pane.Actions belongs directly under Pane.Header'>
  <Guideline.Do code={`<Pane.Header backHref='/events'>\n  <Pane.Title>Midnight Frequency</Pane.Title>\n  <Pane.Actions>\n    <Button>Publish</Button>\n  </Pane.Actions>\n</Pane.Header>`}>
    Put actions directly in `Pane.Header`, so they take their cell opposite
    Back.
  </Guideline.Do>
  <Guideline.Dont code={`<Pane.Header backHref='/events'>\n  <div className='flex justify-between'>\n    <Pane.Title>Midnight Frequency</Pane.Title>\n    <Pane.Actions>…</Pane.Actions>\n  </div>\n</Pane.Header>`}>
    Wrap them. Grid placement only reaches direct children, so the actions
    render below the top row.
  </Guideline.Dont>
</Guideline>

- A pane can sit anywhere under `Navigator.Content`, such as in a route, a
  parallel-route slot or your own component. With no `Pane` at all,
  `Navigator.Content` warns in development.
- `primaryNav` sets what the phone bar does while the pane is on top. `auto`,
  the default, collapses the bar to the active tab as the pane scrolls.
  `visible` keeps it, and `hidden` removes it for a pushed screen, like iOS's
  `hidesBottomBarWhenPushed`.
- A pane scrolls natively, and `List` doesn't virtualise. That is fine into the
  hundreds of rows. For thousands, virtualise against the viewport at
  `[data-slot="pane-viewport"]`.

## Accessibility

- The pane renders a `<section>`. Pass `aria-label` to make it a named region.
- `Pane.Title` is an `<h2>`, so it never clashes with the page's `<h1>`.
  `Pane.BodyTitle` is an `<h1>`, because it is the page's own heading. Use at
  most one per pane, and no other `<h1>` beside it.
- Back is an `IconButton` labelled "Back", or "Back to Events" with
  `backLabel='Events'`.
- Close is an `IconButton` labelled "Close". It uses `onClose`, then `onBack`,
  then `backHref`.
- `Pane.Search` is a search field named by its `aria-label` or placeholder. Its
  Cancel button is labelled "Cancel search", and Escape also clears the field.
- A pane that doesn't fit, covered in the stack or dropped from the columns, is
  hidden from taps and assistive technology.
