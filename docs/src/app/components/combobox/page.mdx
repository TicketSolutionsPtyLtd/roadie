A searchable dropdown for filtering and selecting from a list of options.

## Import

```tsx
import { Combobox } from '@oztix/roadie-components/combobox'
```

## Examples

### Default

```tsx-live
function ComboboxDefault() {
  const bands = [
    'Powderfinger',
    'Custard',
    'Regurgitator',
    'The Go-Betweens',
    'Violent Soho',
    'DZ Deathrays',
    'Ball Park Music',
    'The Goon Sax',
    'Cub Sport',
    'The Jungle Giants',
  ]

  return (
    <Combobox items={bands}>
      <Combobox.InputGroup>
        <Combobox.Input placeholder='Search bands...' />
        <Combobox.Trigger />
      </Combobox.InputGroup>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.List>
              {(band) => (
                <Combobox.Item key={band} value={band}>
                  {band}
                  <Combobox.ItemIndicator />
                </Combobox.Item>
              )}
            </Combobox.List>
            <Combobox.Empty>No bands found</Combobox.Empty>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox>
  )
}
```

### Composition

#### With Field

Wrap Combobox in [Field](/components/field) for consistent layout, labels, and
error handling. Field.Label's `htmlFor` wires directly to the Combobox input:
clicking the label focuses the search field.

```tsx-live
function ComboboxWithField() {
  const bands = [
    'Powderfinger',
    'Custard',
    'Regurgitator',
    'Violent Soho',
    'DZ Deathrays',
    'Ball Park Music',
  ]

  return (
    <Field required>
      <Field.Label showIndicator>Favourite band</Field.Label>
      <Combobox items={bands}>
        <Combobox.InputGroup>
          <Combobox.Input placeholder='Search bands...' />
          <Combobox.Clear />
          <Combobox.Trigger />
        </Combobox.InputGroup>
        <Combobox.Portal>
          <Combobox.Positioner>
            <Combobox.Popup>
              <Combobox.List>
                {(band) => (
                  <Combobox.Item key={band} value={band}>
                    {band}
                    <Combobox.ItemIndicator />
                  </Combobox.Item>
                )}
              </Combobox.List>
              <Combobox.Empty>No bands found</Combobox.Empty>
            </Combobox.Popup>
          </Combobox.Positioner>
        </Combobox.Portal>
      </Combobox>
    </Field>
  )
}
```

#### With rich items

Use custom markup inside `Combobox.Item` to show metadata like a subtitle or
secondary label alongside the primary text. Pass the item itself as `value`, and
use `itemToStringLabel` to set the text the input shows and filters on.

```tsx-live
function ComboboxRichItems() {
  const venues = [
    { name: 'The Longacre', location: 'Fortitude Valley, QLD' },
    { name: 'The Anchorage', location: 'Newstead, QLD' },
    { name: 'The Burrow', location: 'Fortitude Valley, QLD' },
    { name: 'The Tusk Room', location: 'Fortitude Valley, QLD' },
    { name: 'The Palisade Theatre', location: 'Woolloongabba, QLD' },
    { name: 'Meridian Stage', location: 'South Bank, QLD' },
    { name: 'The Signal Hall', location: 'Fortitude Valley, QLD' },
    { name: 'The Amber Lodge', location: 'Fortitude Valley, QLD' },
  ]

  return (
    <Combobox items={venues} itemToStringLabel={(venue) => venue.name}>
      <Combobox.InputGroup>
        <Combobox.Input placeholder='Search venues...' />
        <Combobox.Clear />
        <Combobox.Trigger />
      </Combobox.InputGroup>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.List>
              {(venue) => (
                <Combobox.Item key={venue.name} value={venue}>
                  <div className='grid gap-0.5 min-w-0'>
                    <span className='truncate font-medium'>{venue.name}</span>
                    <span className='truncate text-xs text-subtle'>{venue.location}</span>
                  </div>
                  <Combobox.ItemIndicator />
                </Combobox.Item>
              )}
            </Combobox.List>
            <Combobox.Empty>No venues found</Combobox.Empty>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>

  )

```

### Multiple selection

Set `multiple` to pick more than one value. `Combobox.Value` hands the current
values to a function; render a `Combobox.Chip` for each one inside
`Combobox.Chips`, with the input last. Put the text in `Combobox.ChipLabel` so a
long value truncates. The input group grows as the chips wrap.

```tsx-live
function ComboboxMultiple() {
  const genres = [
    'Rock',
    'Indie',
    'Hip hop',
    'Electronic',
    'Jazz',
    'Folk',
    'Country',
    'Metal',
    'Punk',
    'Soul',
  ]

  return (
    <Field>
      <Field.Label>Genres</Field.Label>
      <Combobox items={genres} multiple defaultValue={['Indie', 'Folk']}>
        <Combobox.InputGroup>
          <Combobox.Value>
            {(value) => (
              <Combobox.Chips
                aria-label={value.length > 0 ? 'Selected genres' : undefined}
              >
                {value.map((genre) => (
                  <Combobox.Chip
                    key={genre}
                    aria-label={genre}
                    aria-description='Press Backspace or Delete to remove'
                  >
                    <Combobox.ChipLabel>{genre}</Combobox.ChipLabel>
                    <Combobox.ChipRemove aria-label={`Remove ${genre}`} />
                  </Combobox.Chip>
                ))}
                <Combobox.Input
                  placeholder={value.length > 0 ? '' : 'Search genres...'}
                  aria-description={
                    value.length > 0
                      ? `${value.length} selected. Press Left Arrow to move to them`
                      : undefined
                  }
                />
              </Combobox.Chips>
            )}
          </Combobox.Value>
          <Combobox.Trigger />
        </Combobox.InputGroup>
        <Combobox.Portal>
          <Combobox.Positioner>
            <Combobox.Popup>
              <Combobox.List>
                {(genre) => (
                  <Combobox.Item key={genre} value={genre}>
                    {genre}
                    <Combobox.ItemIndicator />
                  </Combobox.Item>
                )}
              </Combobox.List>
              <Combobox.Empty>No genres found</Combobox.Empty>
            </Combobox.Popup>
          </Combobox.Positioner>
        </Combobox.Portal>
      </Combobox>
    </Field>
  )
}
```

## Guidelines

### When to use Combobox

Use Combobox when the user needs to **search or filter** a list, or when options
are **loaded from an API**. The input lets users narrow results by typing. They
usually know roughly what they're looking for.

- Venue or event search
- Assignee pickers (team members from an API)
- Tag or category selection with many options
- Any list over ~15 items
- Lists that load asynchronously

### When to use Select instead

If the list is **short, fixed, and fully known** (under ~15 items), use
[Select](/components/select). Users browse rather than search. No text input
needed.

### Combobox vs Autocomplete

If the user's typed value is always valid and suggestions just help, use
[Autocomplete](/components/autocomplete). Think address fields or search bars.

| Question | Select | Combobox | [Autocomplete](/components/autocomplete) |
|---|---|---|---|
| User types to filter? | No | Yes | Yes |
| Must pick from the list? | Yes | Yes | No, typed value is valid |
| Options from an API? | No | Yes | Yes |
| Custom/free-text value? | No | No | Yes |
| Primary interaction | Browse and pick | Search and pick | Type with suggestions |
| Typical list size | 2-15 items | 10-500+ items | Any |

### Filtering

Pass the `items` prop to `Combobox` root for built-in client-side filtering. Use
`Combobox.List` with a render function child to template each filtered item:

```tsx
<Combobox items={bands}>
  ...
  <Combobox.List>
    {(band) => <Combobox.Item value={band}>{band}</Combobox.Item>}
  </Combobox.List>
  <Combobox.Empty>No results</Combobox.Empty>
</Combobox>
```

`Combobox.Empty` only renders when the filtered list is empty. It requires the
`items` prop on root.

### Async loading

For server-side search, update the `items` prop as results arrive. Use
`Combobox.Status` to announce state changes to screen readers:

```tsx
<Combobox items={results} onInputValueChange={(value) => fetchResults(value)}>
  ...
  <Combobox.Status>{isLoading ? 'Loading...' : `${results.length} results`}</Combobox.Status>
</Combobox>
```

## Accessibility

- **Arrow keys** move through the list; **Enter** picks the highlighted item
  and **Escape** closes the popup. Typing filters the list as you go.
- With `multiple`, **Backspace** in an empty input removes the last chip.
  **Left Arrow** from the start of the input moves to the chips, **Left** and
  **Right** move between them (swapped in a right-to-left layout), and
  **Backspace** or **Delete** removes the focused one. Focus moves to the
  next chip, or the previous one after the last, and returns to the input
  once no chips are left.
- **Escape** while the popup is closed clears every value, not just the last
  one.
- `Combobox.Chips` becomes a toolbar once it holds chips, so screen readers
  stay in focus mode while the arrows move between them. Name it with
  `aria-label` while it holds chips.
- `Combobox.ChipRemove` stays out of the tab order. Click it to remove a chip;
  from the keyboard, press Backspace on the chip. Leave it out of a `readOnly`
  combobox, where it can't remove anything.
- `aria-description` on the chip and input, as in the example, adds a hint for
  screen readers that support it. The labels must make sense without it.
- Use a `<label>` or `Combobox.Label` to name the input.
- `Combobox.ItemIndicator` shows a check on the selected item, include it for clarity.
- `Combobox.Empty` announces "no results" to screen readers automatically.
- `Combobox.Status` is a live region, use it for async status like loading or result counts.

## Hooks

### useFilter

```tsx
function useFilter(options?: FilterOptions): Filter
```

Base UI's item matcher, re-exported for filtering `items` yourself before
passing them to `Combobox` (server-side search, custom ranking) rather than
relying on the built-in client-side filter.

| Param | Type | Description |
| --- | --- | --- |
| `options.multiple` | `boolean` | Whether the combobox is in multiple selection mode. Default `false`. |
| `options.value` | `any` | The current value, kept visible even while the query no longer matches it. |
| `options.locale` | `Intl.LocalesArgument` | Locale for string comparison. Defaults to the runtime locale. |

Returns a `Filter`:

| Field | Type | Description |
| --- | --- | --- |
| `contains` | `(item, query, itemToString?) => boolean` | Whether the item matches the query anywhere. |
| `startsWith` | `(item, query, itemToString?) => boolean` | Whether the item starts with the query. |
| `endsWith` | `(item, query, itemToString?) => boolean` | Whether the item ends with the query. |
