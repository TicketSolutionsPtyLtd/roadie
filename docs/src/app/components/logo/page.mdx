# Logo

The Oztix logo, always in its fixed brand colour.

## Import

```tsx
import { Logo } from '@oztix/roadie-components/logo'
```

## Examples

### Default

```tsx-live
<Logo />
```

### Variants

`normal` is the mark and the wordmark together. `mark` is the mark alone, for tight spaces such as an app icon or a collapsed navigation. `wordmark` is the word alone.

```tsx-live
<div className='grid justify-items-start gap-6'>
  <Logo variant='normal' />
  <Logo variant='mark' />
  <Logo variant='wordmark' />
</div>
```

### Product

`product` pairs the mark with a product name, rendered as live text in place of the wordmark. When it's set, `variant` is ignored.

```tsx-live
<Logo product='Studio' />
```

### Sizes

The logo's height is set with the `size` prop, not a className. One value scales the mark, the gap and the product name together. `xs` is 20px, `sm` 24px, `md` 32px (the default), `lg` 40px, `xl` 48px.

Logo sizes sit one step below Button and IconTile, whose `md` is 40px, so a `size='md'` logo pairs with a `size='sm'` button.

```tsx-live
<div className='grid justify-items-start gap-6'>
  <Logo size='xs' />
  <Logo size='sm' />
  <Logo size='md' />
  <Logo size='lg' />
  <Logo size='xl' />
  <Logo product='Studio' size='lg' />
</div>
```

### Colour

The logo's colour is fixed. It is always Oztix blue, identical in light and dark mode, and unaffected by a surrounding intent.

```tsx-live
<div className='flex flex-wrap items-center gap-6'>
  <Logo />
  <div className='intent-danger'>
    <Logo />
  </div>
</div>
```

### Collapsing

The `logo-wordmark` and `logo-product` slots hold their own gap and clip, so a parent can collapse either to the mark's square by animating its `grid-template-columns` from `1fr` to `0fr`.

## Guidelines

<div className='grid gap-8'>

<Guideline title='Size the logo with the size prop'>
  <Guideline.Do code={`<Logo size='lg' />`}>
    Set one height through <code>size</code>. The width follows the logo's proportions.
  </Guideline.Do>
  <Guideline.Dont code={`<Logo className='h-12 w-40' />`}>
    Don't set a width or a separate height. That stretches or crops the artwork and leaves the gap and product name at the old size.
  </Guideline.Dont>
</Guideline>

<Guideline title='Keep product names short'>
  <Guideline.Do example={<Logo product='Studio' />}>
    Use the product's one- or two-word name, in title case.
  </Guideline.Do>
  <Guideline.Dont example={<Logo product='Oztix Studio' />}>
    Don't repeat "Oztix" or add a tagline. The mark already says Oztix, and the name never wraps.
  </Guideline.Dont>
</Guideline>

<Guideline title='The logo colour is fixed'>
  <Guideline.Do code={`<Logo />`}>
    The logo is always Oztix blue. It doesn't take an intent or a colour prop, and it doesn't follow a surrounding intent.
  </Guideline.Do>
  <Guideline.Dont code={`<Logo className='text-[#0191eb]' />`}>
    Don't hard-code a colour. It won't change with the theme.
  </Guideline.Dont>
</Guideline>

</div>

## Accessibility

- The logo is one image with the accessible name "Oztix". A product logo is named "Oztix" plus the product, such as "Oztix Studio".
- Pass `aria-label` to name it something else, such as "Oztix home" inside a link.
- When the logo sits next to text that already says Oztix, pass `aria-hidden` and it drops its role and name.
- The inner SVGs are always hidden from assistive technology.
- The logo is always left to right, so a right-to-left page never mirrors the lockup. It takes no `dir` prop.
