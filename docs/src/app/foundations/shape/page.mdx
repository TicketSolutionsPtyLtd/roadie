Roadie uses Tailwind's built-in border-radius scale to create a consistent,
rounded visual language that progresses from inline elements to full
containers. Soft corners signal approachability.

## Radius scale

The scale runs from inline marks to edge-to-edge hero surfaces. Roadie uses
Tailwind's built-in radius utilities up to `rounded-4xl` and adds three
extended tiers (`rounded-5xl`, `rounded-6xl`, and `rounded-7xl`) for large
promotional layouts. Never use arbitrary values like `rounded-[2.5rem]`. Stick
to the named utilities so the scale stays consistent.

On the docs site, each step of the scale is a tile with its class and value.

<RadiusScale />

| Tier      | Class          | Use for                                         |
| --------- | -------------- | ----------------------------------------------- |
| Inline    | `rounded-sm`   | Marks, highlights                               |
| Small     | `rounded-md`   | Inline code, code blocks, prose images          |
| Field     | `rounded-lg`   | Inputs, textareas, select triggers, radio items |
| Container | `rounded-xl`   | Cards, select popups, radio cards, popovers     |
| Large     | `rounded-2xl`  | Modals, dialogs, Navigator panes                |
| Sheet     | `rounded-4xl`  | Drawers, from any side                          |
| Hero      | `rounded-5xl`  | Hero cards, collection headers                  |
| Feature   | `rounded-6xl`  | Feature banners, spotlight surfaces             |
| Oversize  | `rounded-7xl`  | Edge-to-edge promotional layouts                |
| Full      | `rounded-full` | Buttons, badges, avatars, pills                 |

## Component usage

Which components use which tier. These are the defaults. Override with
`className` when a specific context requires it.

| Component                   | Tier      | Class          |
| --------------------------- | --------- | -------------- |
| Button                      | Full      | `rounded-full` |
| Badge                       | Full      | `rounded-full` |
| Card                        | Container | `rounded-xl`   |
| Dialog                      | Large     | `rounded-2xl`  |
| Drawer                      | Sheet     | `rounded-4xl`  |
| Select trigger              | Field     | `rounded-lg`   |
| Select popup                | Container | `rounded-xl`   |
| Input                       | Field     | `rounded-lg`   |
| Textarea                    | Field     | `rounded-lg`   |
| RadioGroup (default)        | Field     | `rounded-lg`   |
| RadioGroup (card)           | Container | `rounded-xl`   |
| Code                        | Small     | `rounded-md`   |
| Mark and Highlight          | Inline    | `rounded-sm`   |
| Prose (code blocks, images) | Small     | `rounded-md`   |

## Guidelines

- Prefer the standard tier for each element type. Override it with
  `className` only when a specific context demands it.
- When in doubt, round up to the next tier for a softer feel. The brand leans
  soft.
- Keep `rounded-2xl` for top-layer UI, such as modals and dialogs, and the
  Navigator's panes. Don't use it on inline components.
- Never mix custom pixel values with the Tailwind scale. Stick to the utility
  classes.
- Focus rings follow the radius by themselves. Roadie's `is-interactive` and
  `is-interactive-field` utilities handle focus ring radius, so no separate
  token is needed.

  <Guideline.Do
