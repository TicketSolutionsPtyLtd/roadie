One number with its change, what it compares against, and its recent trend.

## Import

```tsx
import { StatTile } from '@oztix/roadie-components/stat-tile'
```

## Examples

### Default

```tsx-live width=72
<StatTile label='Tickets sold' value={1842} delta={{ value: 214 }} context='This week, of 2,400' />
```

### With a trend

```tsx-live width=72
<StatTile
  label='Tickets sold'
  value={1842}
  delta={{ value: 214 }}
  context='Last 20 days'
  trend={[40, 62, 70, 88, 95, 120, 131, 160, 172, 190, 214, 240, 262, 300, 330, 351, 380, 420, 470, 520]}
/>
```

### With a target

```tsx-live width=72
<StatTile
  label='Sell-through'
  value={0.77}
  format='percent'
  delta={{ value: 9, format: 'points' }}
  context='Week target is 85%'
  trend={[0.31, 0.36, 0.41, 0.46, 0.52, 0.57, 0.62, 0.67, 0.71, 0.77]}
  reference={{ value: 0.85, label: 'Target' }}
/>
```

### When lower is better

```tsx-live width=72
<StatTile
  label='Refund rate'
  value={0.012}
  format='percent'
  delta={{ value: -0.3, format: 'points', goodWhen: 'down' }}
  context='On last month'
/>
```

### Several metrics

Show each metric in its own tile, with its `trend`. Follow the row with a [Chart](/charts/chart) per metric when people need the detail.

```tsx-live width=180
<div className='grid grid-cols-[repeat(auto-fit,minmax(10rem,1fr))] gap-3'>
  <StatTile label='Sales' value={1530} delta={{ value: 220 }} context='Since yesterday' trend={[420, 600, 860, 1000, 1310, 1530]} />
  <StatTile label='Sales value' value={84150} format='compactCurrency' delta={{ value: 12100, format: 'compactCurrency' }} context='Since yesterday' trend={[23100, 33000, 47300, 55000, 72050, 84150]} />
  <StatTile label='Sold' value={0.64} format='percent' delta={{ value: 9, format: 'points' }} context='Of 2,400' trend={[0.18, 0.25, 0.36, 0.42, 0.55, 0.64]} />
</div>
```

### States

```tsx-live layout=stack width=72
{/* Loading */}
<StatTile label='Tickets sold' value={0} state='loading' />
{/* Not enough history */}
<StatTile label='Tickets sold' value={180} trend={[95, 85]} context='On sale 2 days' />
{/* Stale */}
<StatTile label='Tickets sold' value={1842} state='stale' staleLabel='As of 10:42am' />
```

## Guidelines

- Keep the label to about 19 characters and the context to about 20, so the tile fits at phone width.
- Keep the delta short next to the value. Put what it compares against on the context line.
- In a [dashboard with a period](/charts/dashboards#periods-and-comparisons), mark a delta against the previous period or year `comparison: true`. The context line then names the comparison, and the delta follows the period.
- Set `goodWhen='down'` for numbers where falling is good, such as refunds.
- Pass `trend` whenever history exists. The sparkline hides itself below 5 points.
- Use a `reference` for a target or benchmark, not a second series.
- Don't make tiles switch a chart below them. People don't notice tiles are clickable, and hiding two or three metrics behind a click makes them harder to compare. Show every metric, as a row of tiles with `trend`, then a Chart for each one.

## Accessibility

- The tile is an article named by its label. It isn't a landmark, so a dashboard can repeat a label across sections.
- The delta reads as a sentence, such as "up 214, better".
- The sparkline is hidden from screen readers, because the text already says it.
