Add `FileUpload` (`@oztix/roadie-components/file-upload`), a file field that checks each file before taking it. `FileUpload.Trigger` opens the picker, the value is a `File[]` that a form posts under `name`, and `accept`, `maxFileSize` and `minFileSize` turn files away with a code and a message that shows in `Field.ErrorText`.
