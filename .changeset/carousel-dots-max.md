`Carousel.Dots` takes `max`, the most dots to draw at once. With more slides, the dots show a window that slides to keep the current dot in the middle, and the dot at each end shrinks while there are slides past it. On an `emphasis-strong` surface the current dot now takes the surface's text colour, so it no longer disappears on an accent band, and the current dot no longer lifts on hover, since pressing it does nothing.
