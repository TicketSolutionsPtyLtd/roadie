`/roadie:release` drafts an optional release note for the docs changelog: a title, a summary, and the highlights in order, for a docs PR once Version Packages merges. It also lists the docs pages due a status promotion. Both steps are required, and the hand-off reports each one, with "nothing due" and "no note needed" as valid answers. `/roadie:pr` checks a changeset's wording, so a new component or package gets its card on the changelog.
