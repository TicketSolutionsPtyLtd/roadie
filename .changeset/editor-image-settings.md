'@oztix/roadie-editor': minor
---

Add Image settings, in place of the image toolbar's Alt text. It edits the image's link, where an email's image links to (a web address or a link variable), its width, Full or Fit, its alignment when it fits, and its alt text, each applied as it's made: Escape puts the image back, and a click away keeps the changes as one step to undo. The Image control and the `/` menu's Image now add an image from its link in every preset that holds images, https only in an email, with Upload an image beside it when there's an `onUploadImage`.
