Add Image settings, in place of the image toolbar's Alt text. It edits the image's link, where an email's image links to (a web address or a link variable), its width, Full or Fit, its alignment when it fits, and its alt text, each applied as it's made: Escape puts the image back, and a click away keeps the changes as one step to undo. The Image control and the `/` menu's Image now add an image from its link in every preset that holds images, https only in an email, with Upload an image beside it when there's an `onUploadImage`. Image settings also sets a page image's width, alignment and caption, and opens from the bottom on a phone. The No alt text badge now shows only on a selected image, on an opaque chip. Its alignments read Start, Centre and End, its source field is Image address, and on a phone it takes half the screen with no blur, the image kept above it.

A gap cursor between blocks, such as between an image and a section, is now a line across the section, column or page it's in, rather than a 20px mark over the block before it. Image settings' Start and End follow the text's direction.
