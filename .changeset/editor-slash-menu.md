Add the insert menu to the `blocks` preset: type `/` to insert a paragraph, a heading, a list, a quote, a divider, an image, an embed, or a table, filtered as you type.

It's the same menu as the `email` preset's. Image shows with `onUploadImage` and opens the file picker, and Embed opens the Embed popover. In both presets the menu now closes when focus leaves the editor, one undo takes an inserted block back to what you typed, and Shift+Enter or Mod+Enter breaks the line instead of inserting.
