Update interactive emphasis so a fill or shadow class you add holds through hover, focus, and press, as a border class already did. A checked Checkbox or RadioGroup card now keeps its accent fill on hover, an open subtler Select keeps its open fill, and a fill class on an interactive subtler element shows at rest. `is-active` now presses a subtle or subtler surface as `:active` does. If you relied on the emphasis replacing your class on hover, add a `hover:` class instead.
