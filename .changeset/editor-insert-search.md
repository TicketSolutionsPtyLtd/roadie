The `/` menu finds blocks by more names, such as `/youtube` and `/link` for Embed, `/h1` and `/title` for a heading, `/img`, `/ul`, `/ol`, `/hr`, `/---`, `/>`, and `/btn` or `/cta` for an email's button, matching the start of each word. When nothing matches, a No blocks match row keeps the menu open, so Enter no longer commits the typed `/` text, until a space follows. Each block that markdown makes shows its shortcut, such as `##` or `1.`, on devices with a mouse or trackpad.
