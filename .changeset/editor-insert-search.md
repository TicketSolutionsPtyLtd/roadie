The `/` menu finds blocks by more names, such as `/youtube` and `/link` for Embed, `/h1` and `/title` for a heading, `/img`, `/ul`, `/ol`, `/hr`, `/---`, `/>`, and `/btn` or `/cta` for an email's button, matching the start of each word, with a name that starts with what's typed listed first, so `/2` offers 2 columns before Heading 2. When nothing matches, a No blocks match row keeps the menu open, so Enter no longer commits the typed `/` text, until a space follows. Each block that markdown makes shows its shortcut, such as `##` or `1.`, only where a mouse or trackpad is attached (`any-pointer: fine`). A block chosen with `/` at the start of a line with text now goes before that line.
