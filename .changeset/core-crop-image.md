`cropImage(source, value, { width?, type?, quality? })` in `@oztix/roadie-core/image` draws the crop an `ImageCrop` value describes, turned by its rotation, and returns it as a Blob. `source` is a File, Blob or URL. It runs on an `OffscreenCanvas` where there is one.
