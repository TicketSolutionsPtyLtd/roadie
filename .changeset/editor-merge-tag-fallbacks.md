Add `fallback` to `EditorVariable`, which a merge tag takes as it's inserted. A tag for a variable with no fallback goes in with the caret after it, so the sentence carries on, and Edit merge tag on it opens with focus in Fallback. Each chip shows its fallback after its label, as "First name · there", in the subtler text colour, or a warning dot when it has none. The merge tag form's title starts at its edge rather than centred.
