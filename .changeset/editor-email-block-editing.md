Add buttons, column counts, and spacer heights to the `email` preset's editing. Type `/` and choose Button to add one, with a link that must be https, http, mailto, or tel, and its label selected to type over. Enter in a button starts a new paragraph after it. A button's toolbar edits its link or removes it, columns get a menu of 2, 3, or 4 (a removed column's blocks move into the last column left), and a selected spacer gets a Height menu.
