Add `Toggle` and `ToggleGroup`, built on Base UI's toggle and toggle group
primitives. `Toggle` is a pressed or unpressed button that takes Button's sizes
and steps up one emphasis when pressed. `ToggleGroup` is a segmented control: a
sunken track with a raised pill that slides to the pressed item. It is single
select by default and never ends up empty, takes `multiple` for independent
toggles, and has `size` (matching Button heights), `direction` and `disabled`.
